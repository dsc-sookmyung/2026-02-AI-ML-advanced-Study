# 신경망과 역전파 (Stanford CS231N)

신경망의 구조와 이를 학습시키기 위한 핵심 알고리즘인 역전파를 다룹니다.

## 1. 신경망과 다층 퍼셉트론

- **기본 구조:** 입력층, 은닉층(Hidden Layer), 출력층으로 구성되며, 각 층은 가중치(W)와 편향(Bias)의 연산으로 연결됩니다.
- **비선형 활성화 함수 (Activation Function):**
    - 단순 선형 연산만으로는 복잡한 문제를 해결할 수 없기에 **비선형성**을 도입합니다.
    - **ReLU (Rectified Linear Unit):** 가장 널리 사용되는 기본 선택지입니다 (18:46).
    - **주의:** *Sigmoid*나 *Tanh*는 기울기 소실(Vanishing Gradient) 문제로 인해 중간 층에서는 잘 사용하지 않습니다 (20:53).
- **모델 설계 전략:** 신경망의 크기(노드 수)를 조절하기보다, **정규화(Regularization)** 하이퍼파라미터($\lambda$)를 조절하여 과적합(Overfitting)을 방지하는 것이 효율적입니다 (28:26 - 32:46).

## 2. 역전파와 계산 그래프

- **계산 그래프 (Computational Graphs):** 복잡한 미분 과정을 모듈화하여 관리하는 도구입니다.
- **연쇄 법칙 (Chain Rule):** 역전파의 핵심으로, 상류에서 내려오는 그래디언트(Upstream Gradient)와 해당 노드의 국소 그래디언트(Local Gradient)를 곱해 하류로 전달합니다.
- **역전파 핵심 패턴:**
    1. **Add Gate:** 그래디언트를 그대로 분배(Distributor)합니다.
    2. **Multiply Gate:** 서로의 값을 교환(Swap)하여 곱합니다.
    3. **Max Gate:** 최댓값이 있던 경로로 그래디언트를 라우팅합니다.

## 3. 실무적 고려 사항

- **벡터/행렬 연산:** 실제 구현 시 거대한 야코비안(Jacobian) 행렬을 일일이 생성하지 않고, 행렬 곱셈의 성질을 이용하여 효율적으로 구현합니다.
- **분석적 그래디언트(Analytical Gradient):** 수학적 유도를 통해 직접 구현하는 것이 표준이며, 구현 오류 확인을 위해 수치적 그래디언트(Numerical Gradient)를 검증용으로 사용합니다.

# 이미지 분류를 위한 CNN(Convolutional Neural Networks)

## 1. 딥러닝 파이프라인의 기초 복습

딥러닝 시스템을 구축하는 4단계 기본 공식을 강조합니다.

- **데이터 형식**: 이미지를 텐서(Tensor) 구조로 정의합니다.
- **모델 설계**: 가중치 행렬 $W$를 사용하여 입력을 점수로 변환합니다. (예: $f(x) = Wx$)
- **손실 함수(Loss Function)**: 모델의 예측이 정답과 얼마나 차이 나는지 평가합니다 (Softmax, SVM loss 등).
- **최적화(Optimization)**: 경사하강법을 통해 손실이 가장 적은 최적의 $W$를 찾습니다.
- **역전파(Backpropagation)**: 계산 그래프를 활용해 연쇄 법칙으로 기울기를 구하며, 각 연산 노드는 로컬 API처럼 동작하여 복잡한 네트워크에서도 자동 기울기 계산이 가능합니다.

### 2. 전통적 특징 추출 vs 종단간(End-to-End) 학습

- **과거 방식**: 사람이 직접 디자인한 특징 추출기(Feature Extractor)를 통과시킨 후 분류기를 학습시켰습니다.
- **CNN 방식**: 원본 픽셀에서 최종 점수까지 모든 과정을 데이터와 최적화를 통해 학습합니다. 데이터가 많고 계산 성능이 좋을 때 사람이 만든 특징 추출기보다 훨씬 뛰어난 성능을 보입니다.

### 3. CNN의 핵심 연산

- **합성곱 계층(Convolution Layer)**:
    - 필터를 이미지 위로 슬라이딩하며 지역적 내적을 계산합니다.
    - 이는 이미지의 **템플릿 매칭**과 유사하며, 색상, 가장자리, 특정 질감 등의 특징을 필터가 학습합니다 (46:18).
    - 하이퍼파라미터: 필터의 개수, 크기, 패딩(Padding), 스트라이드(Stride)를 통해 출력 텐서의 크기를 결정합니다.
- **풀링 계층(Pooling Layer)**:
    - 공간적 크기를 줄여(downsample) 연산량을 절감합니다.
    - 가장 많이 쓰이는 방식은 **맥스 풀링(Max Pooling)**으로, 각 영역에서 최댓값만 추출하여 공간 정보를 보존하면서 정보 밀도를 높입니다.

### 4. 중요한 개념: 이동 등변성 (Translation Equivariance)

- 객체가 이미지 안에서 위치를 옮겨도(Translation), 합성곱과 풀링 연산을 적용한 결과물은 동일한 만큼 위치가 이동되어 나타나는 성질입니다.
- 이는 모델이 객체의 '위치'와 상관없이 객체의 '내용'을 동일하게 인식할 수 있게 해주는 수학적 근거가 됩니다.
