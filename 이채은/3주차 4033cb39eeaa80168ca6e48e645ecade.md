# Lecture 6: CNN Architectures

### 1. Normalisation layers

**레이어 정규화의 핵심 아이디어**: 입력 데이터를 스케일링하고 이동시키는 파라미터를 학습하는 것입니다.

- **동작 과정**
    1. 먼저 입력 데이터 x (배치 크기 N x 피처 차원 D)를 정규화하여 각 샘플별 평균(μ)과 표준편차(σ)를 구합니다. (크기: N x 1)
    2. 이후 학습 가능한 파라미터인 감마(γ)와 베타(β)를 사용하여 데이터를 스케일링(확대/축소) 및 시프트(이동)합니다. (크기: 1 x D)
- **레이어 정규화의 종류**
    - **Batch Norm (배치 정규화)**: 개별 채널(C)을 기준으로, 미니 배치 내의 모든 데이터(N)와 공간 차원(H, W)에 대해 정규화를 수행합니다.
    - **Layer Norm (레이어 정규화)**: 각 데이터 샘플(N)을 기준으로, 전체 채널(C)과 공간 차원(H, W)을 모두 합쳐서 정규화를 수행합니다. 배치 크기에 영향을 받지 않습니다.
    - **Instance Norm (인스턴스 정규화)**: 각 데이터 샘플(N)과 각 채널(C)마다 독립적으로 공간 차원(H, W)에 대해서만 정규화를 수행합니다. 주로 스타일 변환(Style Transfer) 같은 작업에 쓰입니다.
    - **Group Norm (그룹 정규화)**: 전체 채널(C)을 몇 개의 그룹으로 쪼갠 뒤, 각 데이터 샘플(N) 내에서 해당 채널 그룹과 공간 차원(H, W)에 대해 정규화를 수행합니다. Batch Norm과 Layer Norm의 절충안 형태입니다.

### 2. Dropout regularization

**드롭아웃 정규화의 핵심 아이디어**: 순방향 전파때마다 무작위로 어떤 뉴런의 노드를 0으로 만드는 것입니다.

- **드롭아웃이 과적합을 막기에 왜 효과적인가?**
    - **중복 표현(Redundant representation) 강제**: 네트워크가 특정 뉴런에만 의존하지 않고, 여러 뉴런이 고루 특징을 학습하도록 만듭니다.
    - **특징들의 상호 적응(Co-adaptation) 방지**: 특정 뉴런들이 항상 함께 활성화되면서 발생할 수 있는 과도한 의존성을 막아줍니다.
- **드롭아웃을 바라보는 새로운 시각**: 드롭아웃을 파라미터를 공유하는 거대한 앙상블 모델을 학습하는 과정으로 볼 수도 있다!
    - **앙상블 모델의 학습**: 노드를 무작위로 끄는 과정(이진 마스크 적용) 하나하나가 마치 새로운 구조의 모델을 하나 만드는 것과 같습니다.
    - **많은 경우의 수**: 4096개의 유닛(노드)을 가진 완전 연결 층(FC layer)의 경우, 노드를 끄고 켜는 경우의 수가 $2^{4096}$ (약 $10^{1233}$)개나 됩니다. 우주에 존재하는 전체 원자 수 보다도 훨씬 많은 어마어마한 숫자입니다.
    - **앙상블 효과**: 거대한 수의 모델들이 내린 결론을 합치는 효과.
- **드롭아웃 : 테스트를 할 때는?**
테스트를 할 때에는 모든 뉴런을 활성화 시키되, 출력값을 스케일링 해줘야 합니다.
    - **이유**: 학습 과정에서는 설정한 확률에 따라 일부 뉴런을 무작위로 끄고 학습했지만, 실제 테스트나 추론 시점에서는 성능을 위해 모든 뉴런을 항상 활성화 상태로 둡니다. 이 경우, 모든 뉴런의 신호가 한 번에 더해지기 때문에 학습할 때보다 전체적인 출력값이 과도하게 커지는 문제가 발생합니다.
    - **해결책**: 테스트 시점의 기댓값이 학습 시점의 기댓값과 동일해지도록, 각 활성화 함수의 출력값에 뉴런을 유지했던 확률을 곱해서 스케일링을 해줍니다.

### 3. Activation function

**활성화 함수의 목적**: 비선형적 요인을 모델에 도입시키려고!

- **시그모이드 함수**: 학습이 누적될수록 gradient vanishing 문제가 심각하기에 이제는 자주 사용하지 않는 방법입니다.
- **ReLU**: 계산하기 간편하고, 뉴런간 값들을 합치기에 매우 빠르기에 많이 사용됩니다. 그러나 여전히 0 이하로 가면 gradient vanishing 문제가 남아있습니다.
- **기타**: 0 주변에서 부드럽게 이어지는 곡선 형태를 띠는 함수들도 있으나 계산이 복잡하여 ReLU보다 연산 비용이 더 높습니다. 또한 입력값이 매우 큰 음수일 경우에는 여전히 gradient vanishing이 발생할 수 있습니다.

### 4. VGGNet architecture

- VGG는 19개의 층을 사용하여 7.3%의 오류율을 달성하며 딥러닝 모델이 깊어지는 트렌드에 중요한 역할을 했습니다.
- 과거 모델들이 7x7 이나 11x11 처럼 큰 필터를 한 번에 사용했던 것과 달리, VGGNet은 **크기가 작은 3x3 필터를 여러 번 겹쳐서 사용**했습니다.
- 이렇게 하면 한 번에 큰 필터를 쓸 때와 동일한 시야를 확보하면서도, 층이 깊어져 신경망이 더 복잡한 특징을 학습할 수 있고(비선형성 증가), 학습해야 할 파라미터(가중치)의 수는 오히려 줄어드는 장점이 있습니다.

### 5. ResNet and residual learning

**ResNet의 등장 배경**: 일반적인 합성곱 신경망을 계속해서 깊게 쌓으면 어떻게 될까?

- 이는 과적합 때문이 아니라 네트워크가 너무 깊어져서 학습(최적화) 자체가 제대로 이루어지지 않는 문제(Degradation)임을 보여줍니다.

**Residual Block**

- **잔차(Residual) 학습**: 이제 레이어들은 전체 출력 $H(x)$를 처음부터 끝까지 학습하는 것이 아니라, 기존 입력에서 추가로 변해야 할 부분인 $F(x)$ (잔차)만 학습하면 됩니다. (최종 수식: $H(x) = F(x) + x$)
- **성능 저하 해결 (Identity mapping)**: 만약 층을 굳이 더 깊게 쌓을 필요가 없는 상황이라면, 모델은 단순히 파라미터들을 0으로 만들어버리면 됩니다 ($F(x)=0$). 그러면 $H(x) = 0 + x = x$ 가 되어 입력값이 그대로 다음 층으로 전달됩니다. 모델 입장에서는 입력을 그대로 복원하는 복잡한 가중치를 찾는 것보다 가중치를 0으로 만드는 것이 훨씬 쉽기 때문에, 층을 100개 이상 아주 깊게 쌓아도 학습이 잘 되고 성능이 높아집니다.

### 6. Weight initialization techniques

- **가중치를 너무 작은 값으로 초기화했을 때 발생하는 문제?**
    - **가중치 초기화**: `W = 0.01 * np.random.randn(Din, Dout)` 코드를 보면 가중치를 설정할 때 0.01을 곱하여 매우 작은 값들로 초기화하고 있습니다.
    - **활성화 값의 소멸 (0으로 수렴)**: 가중치 값들이 너무 작기 때문에, 데이터가 신경망의 여러 층(Layer)을 통과하며 가중치와 곱해질 때마다 그 결괏값(활성화 값)이 계속해서 작아집니다. (첫 번째 층에서는 퍼져 있던 값들이 깊어질수록 급격하게 0으로 쏠림)
- **가중치를 너무 큰 값으로 초기화했을 때 발생하는 문제?**
    - **가중치 초기화 변경**: `W = 0.05 * np.random.randn(Din, Dout)` 으로 표준편차를 약간 더 크게(0.05) 설정했습니다.
    - **활성화 값의 폭발 (Blow up)**: 초기 가중치 값이 너무 크기 때문에, 곱해질수록 결괏값이 기하급수적으로 커집니다. 층이 깊어질수록 평균(mean)과 표준편차(std)가 비정상적으로 증가합니다.
- **Kaiming/MSRA 초기화**
    - **가중치 초기화 공식 변경**: `W = np.random.randn(Din, Dout) * np.sqrt(2/Din)` 으로 가중치를 설정합니다. 입력 노드의 수($Din$)를 고려하여 가중치의 크기를 수식에 맞게 조절합니다.
    - **ReLU 보정 (ReLU correction)**: 활성화 함수로 음수를 0으로 만드는 ReLU를 사용할 때, 절반의 데이터가 0이 되면서 분산이 반토막 나는 현상을 보정하기 위해 식 안에 숫자 2를 넣어 분산을 2배로 보정합니다.
    - **안정적인 활성화 값**: 층이 깊어져도 활성화 값들의 평균과 표준편차가 급격히 변하지 않고 일정하게 유지됩니다.

### 7. Data preprocessing and augmentation

- **데이터 전처리**
    - **채널별 정규화**: 이미지를 구성하는 각 색상 채널(Red, Green, Blue)별로 평균(mean)을 빼고, 표준편차(std)로 나누어 데이터를 정규화합니다.
    - **3개의 숫자**: RGB 이미지의 경우 각 채널에 대한 통계값(R/G/B 채널 평균 및 표준편차)만 구하면 됩니다.
    - **사전 계산 필요**: 모델 학습을 시작하기 전에 전체 학습 데이터셋을 스캔하여 통계값을 미리 계산해 두어야 합니다.
- **데이터 증강 (과적합을 방지하기 위해 사용)**
    - **이미지 로드**: 원본 데이터베이스에서 학습할 이미지와 정답 라벨을 가져옵니다.
    - **이미지 변형 (Transform image)**: 가져온 원본 이미지를 그대로 넣지 않고 무작위로 변형(좌우 반전, 자르기, 색상/밝기 조절 등)을 가합니다.
    - **학습 진행 (Compute loss)**: 변형된 새로운 이미지를 CNN 모델에 입력하여 결과를 예측하고 차이를 계산해 학습시킵니다.

### 8. Transfer learning

**데이터 양이 적을 때 효과적인 방법!**

- **특징 추출**: 방대한 데이터로 이미 학습을 마친 깊은 신경망 구조에서 최종 분류 직전 층의 출력값을 가져옵니다. 이 값은 모델이 이미지를 분석해 낸 핵심 요약본인 고차원의 '특징 벡터(Feature Vector)'가 됩니다.
- **의미적 유사성**: 새로운 테스트 이미지를 입력했을 때, 이 '특징 공간(Feature space)'에서 수학적으로 가장 거리가 가까운 이미지들을 찾으면 픽셀 단위 색상/구도가 달라도 **의미적으로 같은 객체**들이 잘 찾아집니다.
- **결론**: 대규모 데이터로 잘 학습된 CNN 모델이 시각적 특징을 수준 높게 이해하고 있으므로, 이 '특징'을 그대로 가져와 적은 데이터로도 새로운 분류 작업을 쉽게 수행할 수 있습니다.

# Lecture 7: RNN

### 1. RNNs

- **트랜스포머 시대 이전의 기본 모델들**: 현재 딥러닝 자연어 처리 대세인 트랜스포머 기술 등장 이전에 널리 사용되었던 기초 모델들입니다. (RNN 및 LSTM, GRU 등 변형 모델)
- RNN은 새로운 데이터 $x_t$가 들어왔을 때 그것만 독립적으로 처리하는 것이 아니라, 과거의 정보 $h_{t-1}$와 현재의 데이터 $x_t$를 함께 결합하여 새로운 정보 $h_t$로 갱신합니다.

### 2. RNN : Computational Graph

- **가중치 공유**
    - **시간에 따른 계산 흐름**: $h$는 모델의 기억인 은닉 상태, $x$는 각 시간 단계마다 들어오는 입력 데이터, $f_W$는 상태를 갱신하는 연산 블록입니다.
    - **동일한 가중치 행렬 재사용**: 시간($t=1, 2, 3...$)이 흘러 새로운 입력이 들어오고 상태가 계속 업데이트되더라도, 계산을 수행하는 데 사용되는 규칙(가중치 W)은 매 단계마다 바뀌지 않고 똑같은 것을 재사용(공유)합니다.

### 3. Character-level language models

- **어휘 사전 (Vocabulary)**: 예시에서 모델은 'h', 'e', 'l', 'o' 4개의 알파벳만 알고 있다고 가정합니다.
- **입력층 (Input layer)**: 'hello'를 학습시키기 위해 알파벳을 하나씩 순서대로 입력합니다. 위치만 1이고 나머지는 0인 원-핫 인코딩 형태로 변환하여 넣습니다.
- **은닉층 (Hidden layer)**: 직전 단계에서 넘어온 과거의 상태와 새롭게 들어온 현재의 글자를 결합하여 현재 상태를 업데이트합니다.
- **출력층 (Output layer) 및 정답**: 모델은 은닉층 정보를 바탕으로 **다음에 올 글자가 무엇일지 알파벳별로 예측 점수(Score)를 출력**합니다. (h입력 -> e예측, e입력 -> l예측 등)

**테스트(샘플링) 과정 (자신의 출력값을 다음 단계의 입력으로 재사용)**

1. **첫 글자 입력**: 처음에 시작을 알리는 글자(예: "h")를 모델에 입력합니다.
2. **확률 계산 (Softmax)**: 모델은 은닉층을 거쳐 다음에 올 알파벳 확률을 계산합니다.
3. **글자 뽑기 (Sample)**: 계산된 확률 분포를 바탕으로 다음 글자를 예측(뽑기)합니다.
4. **결과를 다시 입력 (Feed back)**: 스스로 예측한 결과를 다음 단계의 새로운 입력으로 다시 집어넣습니다.
5. **반복 생성**: 새로 입력된 문자를 바탕으로 다음 글자를 예측하는 과정을 반복합니다. (실전에서는 정답을 모르기 때문에 모델이 스스로 예측한 결과를 꼬리에 꼬리를 물듯 연결하여 생성)

### 4. RNN tradeoffs

- **RNN의 장점 (Advantages)**
    - **입력 길이 무관**: 짧은 문장이든 긴 문장이든 입력 데이터의 길이에 상관없이 모두 처리할 수 있습니다.
    - **과거 정보 활용**: 현재 시점을 계산할 때 과거의 모든 정보를 이론상 활용할 수 있습니다.

### 6. Image Captioning

CNN과 RNN을 결합하여 이미지에 대한 설명글을 자동으로 생성하는 모델입니다.

- **CNN (시각적 특징 추출)**: 이미지(밀짚모자를 쓴 사람)가 입력되면, CNN 모델이 이를 분석하여 이미지가 담고 있는 핵심 정보(특징 벡터)를 압축해서 추출해 냅니다.
- **RNN (문장 생성)**: CNN이 추출한 '이미지의 요약 정보'를 RNN에 전달합니다. 그러면 RNN은 이 정보를 바탕으로 이미지에 알맞은 단어들을 순서대로 만들어내기 시작합니다.
- **단계별 텍스트 생성 과정**:
    1. RNN에 문장의 시작을 알리는 신호가 들어갑니다.
    2. 모델은 앞서 전달받은 이미지 정보를 바탕으로 첫 번째 단어인 "straw"를 예측하여 출력($y_t$)합니다.
    3. 예측된 "straw"는 다음 단계의 입력($x_t$)으로 다시 들어가고, 이를 바탕으로 다음 단어인 "hat"을 예측합니다.
    4. "hat"이 다시 입력되어 문장이 끝났음을 알리는 "END" 토큰을 예측하며 단어 생성 과정을 마무리합니다.

### 7. LSTM (Long Short Term Memory)

**등장 배경**: 기본 RNN은 구조가 단순하지만, 데이터가 길어지면 과거의 기억을 잘 잊어버리는 문제(기울기 소실, Vanishing Gradients)가 발생합니다. 이를 해결하기 위해 등장한 것이 바로 LSTM입니다.

- **LSTM의 핵심 구조 (4가지 게이트)**
LSTM은 내부에 복잡한 게이트(Gate) 구조를 두어 정보를 얼마나 기억할지, 지울지 세밀하게 조절합니다.
    - **Input gate ($i$)**: 새로운 정보를 셀(Cell)에 쓸지 말지 결정합니다. (whether to write to cell)
    - **Forget gate ($f$)**: 과거의 기억을 지울지 말지 결정합니다. (Whether to erase cell)
    - **Output gate ($o$)**: 현재 셀의 정보를 얼마나 밖으로 내보낼지(드러낼지) 결정합니다. (How much to reveal cell)
    - **Gate gate ($g$)**: 새로운 정보를 셀에 얼마나 쓸지 양을 결정합니다. (How much to write to cell)
- **핵심 메커니즘**
출력 게이트를 통해 현재 상황에 꼭 필요한 정보만 걸러서 다음 단계로 전달합니다.
- **LSTM이 기울기 소멸 문제를 완전히 해결할까?**
    - **정보 보존의 용이성**: LSTM 구조는 기본 RNN보다 긴 시간(여러 타임스텝) 동안 정보를 보존하기가 훨씬 쉽습니다.
    - **예시**: 만약 망각 게이트($f$)가 1 (과거 기억을 모두 유지)이고 입력 게이트($i$)가 0 (새로운 정보는 무시)으로 설정된다면, 내부의 핵심 기억(Cell state)은 값이 변하지 않고 무한히 그대로 보존될 수 있습니다.
