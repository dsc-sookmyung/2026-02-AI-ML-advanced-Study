## Lecture 8. Attention과 Transformer

### 1. Attention

기본적인 Seq2Seq는 입력 문장 전체를 하나의 벡터로 압축한다. 문장이 길어지면 이 벡터에 필요한 정보를 모두 담기 어렵다. Attention을 쓰면 디코더는 단어를 생성할 때마다 입력의 각 위치에 가중치를 매기고, 가중합으로 그 시점에 필요한 문맥 벡터를 만든다.

- **Query (Q)** — 현재 위치에서 어떤 정보가 필요한지 나타내는 벡터
- **Key (K)** — Query와 비교해 각 입력의 관련도를 계산하는 벡터
- **Value (V)** — 관련도에 따라 가중합할 실제 정보

계산 흐름은 `QKᵀ / √dₖ → Softmax → V의 가중합`이다. `√dₖ`로 나누면 내적값이 커져 Softmax가 한쪽에 과도하게 쏠리는 현상을 줄일 수 있다. [Transformer 원 논문](https://arxiv.org/abs/1706.03762)

### . Self-Attention과 Cross-Attention

| 구분 | 동작 방식 |
| --- | --- |
| Self-Attention | Q, K, V를 같은 입력에서 만들어 토큰끼리 정보를 주고받는다. |
| Cross-Attention | Q는 한 입력에서, K와 V는 다른 입력에서 가져온다. 번역에서는 디코더가 인코더의 출력을 참고할 때 쓰인다. |
| Causal Self-Attention | 미래 위치의 점수를 마스킹해 현재 위치와 이전 위치만 참고한다. 다음 토큰을 예측할 때 사용한다. |
| Multi-Head Attention | 여러 헤드가 각자의 가중치로 Attention을 계산하고, 결과를 합쳐 하나의 출력으로 만든다. |

기본 Self-Attention은 위치 정보를 따로 주지 않으면 토큰의 순서를 구별할 수 없다. 그래서 위치 인코딩을 더한다. 모든 토큰 쌍의 관련도를 계산하므로, 일반적인 전체 Self-Attention에서 길이 `N`에 따른 계산량과 가중치 행렬 크기는 `N²`에 비례한다. [Transformer 원 논문](https://arxiv.org/abs/1706.03762)

### 3. Transformer와 ViT

- **Transformer 블록** — Self-Attention으로 토큰 사이의 정보를 섞고, MLP로 각 토큰의 표현을 개별적으로 변환한다. 잔차 연결과 LayerNorm을 함께 사용한다.
- **언어 모델** — 미래 토큰을 가린 상태에서 각 위치의 다음 토큰을 예측한다. 학습할 때는 여러 위치의 예측을 병렬로 계산할 수 있다.
- **Vision Transformer (ViT)** — 이미지를 일정한 크기의 패치(예: 16×16 픽셀)로 나누고 각 패치를 토큰으로 사용한다. 전체 Self-Attention을 쓰면 첫 블록부터 멀리 떨어진 패치끼리도 정보를 주고받을 수 있다.
- **구조 변형** — Pre-Norm은 Attention이나 MLP에 들어가기 전에 정규화한다. RMSNorm은 정규화 방식, SwiGLU는 MLP의 게이트 방식, MoE는 토큰마다 일부 전문가 MLP를 선택하는 방식이다.

## Lecture 9. 객체 탐지·분할과 모델 시각화

### 1. 컴퓨터 비전 작업별 출력

| 작업 | 출력 | 예시 |
| --- | --- | --- |
| 이미지 분류 | 이미지 전체의 클래스 | 사진에 사람이 있다. |
| 의미 분할 | 픽셀마다 클래스 | 사람이 있는 모든 픽셀을 표시한다. |
| 객체 탐지 | 객체마다 클래스와 경계 상자 | 사람 한 명마다 상자를 그린다. |
| 인스턴스 분할 | 객체마다 클래스와 픽셀 마스크 | 사람 한 명마다 윤곽을 따로 표시한다. |

### . 의미 분할과 U-Net

픽셀마다 주변 영역을 잘라 CNN에 넣으면 겹치는 영역을 반복 계산하게 된다. 반대로 전체 해상도를 유지하며 합성곱 층을 깊게 쌓는 방식도 계산 비용이 크다. 그래서 **다운샘플링으로 넓은 범위의 특징을 추출하고, 업샘플링으로 픽셀 단위 출력을 복원**하는 구조를 사용한다.

**U-Net**은 인코더와 디코더의 같은 해상도 층을 스킵 연결로 이어준다. 디코더가 인코더의 고해상도 특징을 다시 활용하므로 물체의 경계처럼 세밀한 위치 정보를 복원하는 데 도움이 된다.

### 3. 객체 탐지 모델의 차이

객체 탐지는 물체가 **무엇인지**를 분류하고 **어디에 있는지**를 경계 상자 좌표로 예측한다. 이미지마다 물체 수가 다르므로, 한 이미지에서 여러 물체의 위치를 효율적으로 찾는 것이 중요하다.

| 모델 | 박스와 클래스를 예측하는 방식 |
| --- | --- |
| R-CNN | 물체가 있을 법한 후보 영역을 먼저 뽑고, 후보마다 CNN을 실행한다. |
| Fast R-CNN | 이미지 전체에 CNN을 한 번 실행한 뒤, 공통 특징 맵에서 후보 영역별 특징을 추출한다. |
| Faster R-CNN | RPN이 공통 특징 맵에서 후보 영역을 만든다. 이후 각 후보의 클래스를 분류하고 박스 좌표를 보정한다. |
| YOLO·SSD | 별도의 후보 영역 생성 단계 없이 박스와 클래스를 직접 예측한다. |
| DETR | 학습된 객체 쿼리로 예측 집합을 만들고, 학습할 때 예측과 정답을 일대일로 매칭한다. |

**RoI Pooling**은 후보 영역을 특징 맵의 격자에 맞춰 고정 크기로 변환한다. 이때 좌표를 반올림해 위치 오차가 생길 수 있다. **NMS**는 서로 많이 겹치는 예측 박스 중 점수가 낮은 박스를 제거한다. 원래 DETR은 학습 중 일대일 매칭을 이용해 추론 단계에서 NMS 없이 예측을 출력한다. [Faster R-CNN 원 논문](https://arxiv.org/abs/1506.01497), [YOLO 원 논문](https://arxiv.org/abs/1506.02640), [DETR 원 논문](https://arxiv.org/abs/2005.12872)

### 4. 모델이 어떤 부분을 참고했는지 살펴보는 방법

- **첫 층 필터 시각화** — 경계나 색 변화처럼 CNN이 초기에 감지하는 패턴을 본다.
- **Saliency Map** — 클래스 점수를 입력 픽셀로 미분해, 점수가 어느 픽셀 변화에 민감한지 표시한다.
- **CAM** — 특징 맵을 클래스별 가중치로 합쳐 관심 영역을 히트맵으로 표시한다.
- **Grad-CAM** — 클래스 점수의 기울기로 특징 맵의 가중치를 구한다. CAM보다 다양한 모델 구조에 적용할 수 있다.
