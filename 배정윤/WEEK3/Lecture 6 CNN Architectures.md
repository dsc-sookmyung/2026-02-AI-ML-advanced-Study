# Layers in CNNs

- CNN은 합성곱, 풀링, 완전 연결, 정규화, 활성화 함수 레이어를 조합해 만든다.
- 드롭아웃은 과적합을 막기 위해 필요할 때 추가한다.

# Normalization Layers

: 레이어에 들어오는 값의 분포를 평균 0, 분산 1 근처로 맞춰서 깊은 신경망도 안정적으로 학습되게 한다.

1. 입력의 평균과 표준편차를 구해 정규화한다.
2. 학습 가능한 파라미터 γ, β로 값의 크기를 다시 조절하고 이동시킨다.
    - 정규화가 오히려 방해가 되는 경우 모델이 스스로 원래 분포로 되돌릴 수 있게 하기 위함이다.

종류 : 평균과 표준편차를 어느 범위에서 구하느냐가 다르다.

| 종류 | 통계를 구하는 범위 | 특징 |
| --- | --- | --- |
| Batch Norm | 미니 배치 안의 모든 샘플, 채널별 | 배치 크기에 영향을 받는다. 테스트 때는 학습 중 모아 둔 평균과 분산을 쓴다 |
| Layer Norm | 샘플 하나 안의 모든 특징 | 배치 크기와 무관하다. Transformer에서 주로 쓴다 |
| Instance Norm | 샘플 하나, 채널 하나 | 스타일 변환에 주로 쓴다 |
| Group Norm | 샘플 하나 안의 채널 묶음 | Layer Norm과 Instance Norm의 중간 형태 |

# Dropout

 : 학습할 때 순전파마다 일부 뉴런을 무작위로 0으로 만든다. 보통 확률 0.5를 쓴다.

왜 과적합을 막는가

- 특정 뉴런에 기댈 수 없으므로 여러 뉴런이 같은 정보를 나눠 갖게 된다.
- 몇몇 뉴런이 항상 함께 움직이며 서로에게 맞춰지는 현상을 막는다.
- 매번 다른 뉴런 조합이 학습되므로 파라미터를 공유하는 수많은 모델을 앙상블하는 것과 비슷하다.
    - 4096개 유닛이면 가능한 조합이 2^4096개로 우주의 원자 수보다 많다.

테스트할 때

- 모든 뉴런을 켜고 출력에 뉴런을 유지했던 확률을 곱한다.
- 모든 뉴런이 켜지면 출력이 학습 때보다 커지므로 기댓값을 학습 때와 맞추기 위해서
- 일반적인 패턴 : 학습 때는 무작위성을 넣고 테스트 때는 그 무작위성을 평균을 내며 데이터 증강도 같은 패턴

# Activation Functions

목적 : 비선형성을 넣는다. 활성화 함수가 없으면 레이어를 아무리 쌓아도 선형 함수 하나와 같다.

| 함수 | 장점 | 단점 |
| --- | --- | --- |
| Sigmoid | 출력이 0~1 사이 | 입력이 크거나 작으면 기울기가 거의 0이 되어 깊은 신경망에서 기울기가 사라진다. 지금은 잘 쓰지 않는다 |
| ReLU | 양수 구간에서 포화되지 않고 계산이 간단하며 수렴이 빠르다 | 출력이 0 중심이 아니다. 음수 입력에서 기울기가 0이라 죽은 뉴런이 생길 수 있다 |
| GELU | 0 근처가 부드러운 곡선이라 학습에 유리하다 | ReLU보다 계산 비용이 크다 |
- 활성화 함수는 보통 합성곱이나 완전 연결 같은 선형 연산 바로 뒤에 둔다.

# CNN Architectures

ImageNet 대회 우승 모델은 해마다 깊어지면서 오류율이 크게 줄었다.

# VGGNet

- 설계 규칙이 단순하다. 합성곱은 모두 3 × 3, 풀링은 모두 2 × 2 최대 풀링만 쓴다.
- 왜 작은 필터를 여러 번 쓰는가?
    - 3 × 3 합성곱을 3번 쌓으면 7 × 7 합성곱 1번과 같은 범위를 본다.
    - 대신 활성화 함수가 3번 들어가 더 복잡한 특징을 표현할 수 있다.
    - 파라미터도 더 적다. 채널 수가 C일 때 3 × 3 세 번은 27C², 7 × 7 한 번은 49C²

# ResNet

등장 배경 : 레이어를 그냥 많이 쌓으면 성능이 좋아질까? 라는 질문.

- 일반 CNN을 20개 레이어에서 56개 레이어로 늘렸더니 테스트 오류뿐 아니라 학습 오류도 더 높았다.
- 학습 데이터에서도 못하므로 과적합이 아니다. 깊은 모델을 최적화하기 어려운 것이 원인.
- 레이어가 항등 함수를 배우는 것조차 어렵다.

**Residual Block**

- 레이어가 출력 전체를 처음부터 배우는 대신 입력에서 얼마나 바꿀지만 배우고 입력을 그대로 더한다.
    - H(x) = F(x) + x
- 굳이 필요 없는 블록이라면 F(x)를 0으로 만들면 된다. 가중치를 0으로 만드는 것은 쉬우므로 항등 함수를 쉽게 배운다.
- 더하기 연산은 역전파 때 기울기를 그대로 통과시키므로 앞쪽 레이어까지 기울기가 잘 전달된다.
- 그 결과 100개가 넘는 레이어를 쌓아도 학습이 잘 된다.

전체 구조

- 처음에 큰 합성곱으로 해상도를 줄이는 stem을 두고 그 뒤에 Residual 블록을 여러 개 쌓는다.
- 단계가 넘어갈 때마다 필터 수는 2배로 늘리고 공간 크기는 절반으로 줄인다.
- 18, 34, 50, 101, 152개 레이어 버전이 있다. 152개 레이어 모델이 2015년 ImageNet 대회 분류, 검출 부문을 모두 우승했다.

# Weight Initialization

- 너무 작게 초기화하면 레이어를 지날 때마다 활성화 값이 작아져 깊은 레이어에서는 거의 0이 된다. 그러면 기울기도 0이 되어 학습이 되지 않는다.
- 너무 크게 초기화하면 활성화 값이 레이어마다 커져 폭발
- Kaiming 초기화 : 고정된 상수 대신 입력 개수 Din에 맞춰 표준편차를 √(2 / Din)로 정한다.
    - ReLU가 음수를 0으로 만들어 분산이 절반으로 줄어드는 것을 2로 보정한 것이다.
    - 레이어가 깊어져도 활성화 값의 분포가 일정하게 유지된다.

# Data Preprocessing and Augmentation

**전처리**

- 학습 데이터 전체에서 RGB 채널별 평균과 표준편차를 미리 구한다.
- 각 픽셀에서 채널 평균을 빼고 표준편차로 나눈다.

**데이터 증강** : 원본 이미지를 무작위로 변형해서 학습한다. 레이블은 그대로 두고 같은 고양이를 다양한 모습으로 보여 주어 과적합을 줄인다.

- 좌우 반전
- 무작위 자르기와 크기 조절, 밝기와 대비 무작위 변경
- Cutout : 이미지 일부를 무작위로 가린다. CIFAR 같은 작은 데이터셋에서 효과적
- 테스트 때도 여러 크기와 위치로 잘라 예측한 뒤 평균 내기도 한다.

# Transfer Learning

: ImageNet처럼 큰 데이터로 미리 학습한 모델은 이미지의 일반적인 특징을 이미 잘 뽑아냄 → 모델을 가져와 내 문제에 맞게 조금만 학습시키면 **데이터가 적어도** 좋은 성능을 낼 수 있다.

- 앞쪽 레이어는 edge나 색처럼 어디에나 쓰이는 특징, 뒤쪽 레이어는 데이터셋에 특화된 특징을 배운다.
- 데이터가 적으면 사전 학습된 레이어는 고정, 마지막 분류 레이어만 새로 초기화해 학습
- 데이터가 많으면 사전 학습된 가중치로 시작해 더 많은 레이어를 미세 조정한다.

# Hyperparameter Selection

1. 초기 손실이 예상값과 맞는지 확인한다. 10개 클래스 Softmax라면 약 2.3이어야 한다.
2. 작은 샘플을 완전히 과적합시켜 본다. 이것도 안 되면 코드에 문제가 있다.
3. 약 100번 반복 안에 손실이 크게 떨어지는 학습률을 찾는다. 1e-1부터 1e-5 사이에서 시도한다.
4. 1~5 에폭 정도로 대략적인 그리드를 돌린다.
5. 범위를 좁혀 더 오래 학습한다.
6. 손실과 정확도 곡선을 보고 5번으로 돌아간다.
