# RNN

: 내부에 은닉 상태를 두고 새 입력이 들어올 때마다 이전 은닉 상태와 현재 입력을 합쳐 은닉 상태를 갱신

- 새 은닉 상태 = f(이전 은닉 상태, 현재 입력).
- 모든 시점에서 같은 함수와 같은 가중치를 쓴다 → 입력 길이가 달라도 하나의 모델로 처리 가능
- Vanilla RNN은 이전 은닉 상태와 현재 입력에 각각 가중치를 곱해 더한 뒤 tanh를 통과시킨다.

# Computational Graph

- RNN을 시간 축으로 펼치면 같은 블록이 반복되는 긴 신경망이 된다.
- 모든 블록이 **같은 가중치 W를 공유**한다.
- W의 기울기는 모든 시점에서 구한 기울기를 더한 값이다.

| 형태 | 계산 방식 | 예시 |
| --- | --- | --- |
| many-to-many | 시점마다 출력과 손실을 계산하고 전체 손실은 그 합이다 | 문장 → 문장 (번역) |
| many-to-one | 마지막 은닉 상태로만 출력을 만든다 | 영상 프레임 → 행동 하나 |
| one-to-many | 입력은 처음에 한 번만 넣고 이후에는 이전 출력을 다음 입력으로 넣는다 | 사진 한 장 → 문장 |
| seq2seq | many-to-one 인코더가 입력 시퀀스를 벡터 하나로 요약하고 one-to-many 디코더가 그 벡터로 출력 시퀀스를 만든다. 기계 번역에 쓰인다 |  |

# Backpropagation Through Time(BPTT)

- **BPTT** : 시퀀스 전체를 순전파해 손실을 구한 뒤 시퀀스 전체를 거꾸로 역전파. 시퀀스가 길면 메모리와 계산이 너무 많이 든다.
- **Truncated BPTT** : 시퀀스를 일정 길이의 덩어리로 나눈다. 은닉 상태는 이어서 넘어가고 역전파만 짧게 나눔(끊음)

# Character-level Language Model

: 지금까지 본 글자들로 다음 글자를 예측한다.

- 사전이 h, e, l, o 네 글자이고 학습 문자열이 "hello"라고 가정
- 각 글자를 원-핫 벡터로 넣고 h → e, e → l, l → l, l → o를 정답으로 학습한다.
- 같은 l이 들어와도 첫 번째는 l, 두 번째는 o를 예측. 은닉 상태가 앞 글자들을 기억하기 때문에 가능. (은닉 상태가 l이 한 번 나왔다는 것을 기억)면 그럴듯한 문장과 코드를 생성한다.
- 은닉 상태의 일부 뉴런은 따옴표 안에 있는지 여부, 현재 줄의 길이, if 문 안에 있는지 여부 같은 해석 가능한 정보를 추적한다.

# RNN Tradeoffs

장점

- 입력 길이에 제한이 없다.
- 이론상 아주 먼 과거 정보도 쓸 수 있다.
- 입력이 길어져도 모델 크기가 그대로다.
- 모든 시점에 같은 가중치를 쓰므로 위치와 상관없이 같은 방식으로 처리한다.

단점

- 앞 시점 계산이 끝나야 다음 시점을 계산할 수 있어 병렬화가 어렵고 느리다.
- 실제로는 먼 과거의 정보에 접근하기 어렵다.

# Image Captioning

 : CNN이 이미지를 특징 벡터로 요약하고 RNN이 그 벡터를 바탕으로 문장을 한 단어씩 만든다.(imageNet 전이학습)

1. 사전 학습된 CNN에서 마지막 분류 레이어를 떼고 그 직전의 특징 벡터를 가져온다.
2. 이미지 벡터를 별도의 가중치로 RNN의 은닉 상태 갱신에 함께 넣는다. 은닉 상태는 이전 은닉 상태, 현재 단어, 이미지 정보로 계산된다.
3. START 토큰으로 시작해 단어를 하나 뽑고 그 단어를 다음 입력으로 넣는 과정을 반복한다.
4. END 토큰이 나오면 멈춘다.

= 그럴듯해 보여도 이미지를 진짜 이해하는 것이 아니라 학습 데이터의 패턴에 의존하므로 엉뚱한 설명을 내놓는 실패 사례 존재.

= 이미지에 대한 질문에 답하기, 이미지에 대한 대화, 언어 지시를 따라 길 찾기 같은 문제에도 같은 방식이 사용

# Vanishing and Exploding Gradients

**기울기 소실과 기울기 폭발**

- Vanilla RNN에서는 기울기가 한 시점 뒤로 갈 때마다 같은 가중치 행렬 W가 반복해서 곱해진다.
- 시퀀스가 길면 같은 행렬을 수십, 수백 번 곱함
    - W가 기울기를 키우는 쪽이면 기울기가 폭발한다.
    - W가 기울기를 줄이는 쪽이면 기울기가 사라진다. tanh의 기울기도 1 이하라서 대부분 이쪽이다.
- **기울기 폭발** : 기울기 크기가 임계값을 넘으면 크기를 줄이는 gradient clipping으로 해결
- **기울기 소실** : 구조 자체를 바꿔야 함 → LSTM

# LSTM

: 은닉 상태와 별도로 장기 기억을 담는 **cell state**를 두고 게이트로 무엇을 지우고 무엇을 쓰고 무엇을 내보낼지 조절한다.

| 기호 | 이름 | 역할 |
| --- | --- | --- |
| f | forget gate | 이전 cell state를 얼마나 지울지 정한다 |
| i | input gate | 새 정보를 얼마나 쓸지 정한다 |
| g | gate gate | 쓸 후보 내용을 만든다. tanh를 통과한다 |
| o | output gate | cell state를 은닉 상태로 얼마나 내보낼지 정한다 |
- 네 게이트는 이전 은닉 상태와 현재 입력으로 한 번에 계산한다.
- f, i, o는 Sigmoid를 거쳐 0~1 사이 값이 되어 일종의 밸브 역할을 한다.
- cell state 갱신 : 기존 기억에 f를 곱해 일부를 지우고 i와 g를 곱한 새 내용을 더한다.
- 은닉 상태는 cell state를 tanh에 통과시킨 뒤 o를 곱해 만든다.

### 기울기 소실이 줄어드는 이유 :

- cell state를 따라 역전파할 때는 f와의 원소별 곱만 일어나 기울기가 흐르는 고속도로가 생김
- ResNet의 Residual 연결과 같은 아이디어.
- f = 1, i = 0이면 cell state의 내용이 바뀌지 않고 계속 보존.
- LSTM이 기울기 소실과 폭발을 완전히 없애지는 않음. 먼 거리의 의존성을 배우기 쉬운 길을 열어 줄 뿐.
- GRU는 LSTM의 게이트 수를 줄여 단순하게 만든 변형이다.
