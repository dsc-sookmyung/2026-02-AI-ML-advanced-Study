# AI 에이전트 개념 정리

> **챗봇 → RAG → AI 에이전트**의 차이를 이해하고, 에이전트의 핵심인 **LLM + 도구 + 반복** 구조를 학습한다.
>
> 참고: [위키독스 - AI 에이전트란 무엇인가](https://wikidocs.net/344425)

## 1. 챗봇 · RAG · AI 에이전트

| 구분 | 핵심 기능 | 예시 |
|---|---|---|
| **챗봇** | LLM이 질문에 답변 | 글쓰기, 코드 설명 |
| **RAG** | 외부 문서를 검색해 근거 기반 답변 | 사내 문서 Q&A |
| **AI 에이전트** | 상황에 따라 도구를 선택하고 여러 단계를 수행 | 정보 검색 → 분석 → 보고서 작성 |

- **RAG**는 정보를 검색하여 답변을 보강하는 기술이다.
- **에이전트**는 검색을 포함한 여러 도구 중 필요한 것을 선택하고, 결과를 확인하며 다음 행동을 결정한다.
- RAG와 에이전트는 별개이지만 **RAG를 에이전트의 도구로 활용**할 수도 있다.

## 2. AI 에이전트의 구성 요소

**AI 에이전트 = LLM + Tools + Loop**

- **LLM**: 요청을 이해하고 다음 행동을 판단한다.
- **Tools**: 웹 검색, 계산기, 데이터베이스, API 등을 통해 실제 작업을 수행한다.
- **Loop**: 도구 실행 결과를 보고 추가 작업이 필요한지 판단하여 반복한다.

```text
사용자 요청
    ↓
LLM의 판단
    ↓
도구 선택 및 실행
    ↓
실행 결과 확인
    ↓
추가 작업 필요? ── Yes → 다시 판단
    │
    No
    ↓
최종 답변
```

> LLM이 직접 도구를 실행하는 것은 아니다. LLM이 호출을 요청하면 외부 실행 시스템이 처리하고 결과를 돌려준다.

## 3. ReAct 패턴

**ReAct = Reasoning + Acting**

에이전트가 판단과 행동을 반복하며 문제를 해결하는 방식이다.

1. **Thought**: 다음에 필요한 작업을 판단한다.
2. **Action**: 적절한 도구를 호출한다.
3. **Observation**: 도구 실행 결과를 확인한다.
4. **Answer**: 정보가 충분하면 최종 답변을 생성한다.

```text
Thought → Action → Observation
   ↑                    │
   └── 추가 작업 시 반복 ┘
              ↓
            Answer
```

예를 들어 '이번 주 기온 평균을 알려줘'라는 요청에는 **날씨 검색 → 기온 데이터 확인 → 계산 → 답변** 순서로 도구를 사용할 수 있다.

## 4. 하이브리드 구조

에이전트의 모든 기능을 LLM으로 구현할 필요는 없다.

| LLM이 적합한 작업 | 일반 코드·규칙이 적합한 작업 |
|---|---|
| 자연어 의도 파악 | 정확한 수치 계산 |
| 작업 계획 및 도구 선택 | DB 조회·저장 |
| 문서 요약 및 결과 설명 | 인증·권한·데이터 검증 |

**핵심 원칙:** 판단과 언어 처리는 LLM, 정확한 실행과 검증은 코드·규칙이 담당한다. 결제·삭제 같은 위험한 작업에는 **사람 승인(Human-in-the-Loop)**을 추가한다.

## 5. 에이전트와 일반 워크플로의 차이

- **워크플로 자동화**: 사람이 미리 정한 순서대로 작업한다.
- **AI 에이전트**: 요청과 중간 결과에 따라 LLM이 다음 작업과 도구를 결정한다.

단순하고 반복적인 업무는 일반 워크플로가 더 안정적일 수 있다.

## 핵심 개념 정리

- **Chatbot**: 질문에 답변하는 시스템
- **RAG**: 외부 자료를 검색해 답변의 근거를 제공하는 방식
- **AI Agent**: 도구 사용과 반복적인 판단으로 여러 단계의 업무를 수행하는 시스템
- **Tool Calling**: LLM이 외부 도구 호출을 요청하는 기능
- **ReAct**: 판단 → 행동 → 관찰을 반복하는 패턴
- **Human-in-the-Loop**: 중요한 실행 전에 사람의 확인·승인을 받는 방식

## 전체 흐름

```text
챗봇
  ↓ 외부 정보가 필요
RAG (검색 + 답변)
  ↓ 여러 도구와 단계별 판단이 필요
AI 에이전트
  ↓
LLM + Tools + Loop
  ↓
ReAct 및 하이브리드 실행
```

> **핵심:** AI 에이전트는 단순히 답변을 생성하는 것을 넘어, 필요한 도구를 선택하고 결과를 확인하면서 작업을 진행하는 시스템이다.
