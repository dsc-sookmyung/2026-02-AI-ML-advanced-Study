# **Self-Attention and Transformers**

## RNN의 한계

RNN은 순서가 있는 입력을 처리하며, 이전 은닉 상태를 이용해 현재 은닉 상태를 계산함

이전 은닉 상태 + 현재 입력 → 현재 은닉 상태

구조의 문제점:

**선형 상호작용 거리(Linear Interaction Distance)**

멀리 떨어진 단어의 정보를 전달하려면, 그 사이의 여러 시간 단계를 거쳐야 함

예: 

> The chef who … was …
> 

이 때 chef와 was는 문법적으로 관련되어 있지만, 문장에서는 멀리 떨어져 있음.

**was의 예측에 chef 정보가 필요 → 여러 은닉 상태를 거쳐 정보를 전달해야함**

→ 단어 사이의 거리가 멀수록 관계의 학습이 어려움

→ 역전파 과정에서도 많은 단계를 거쳐야 하므로 기울기 소실 문제가 발생할 수 있음

LSTM은 기본 RNN보다 장거리 정보를 잘 보존하지만 이 문제를 완벽히 해결하지는 못함

병렬화의 어려움

현재 은닉 상태를 계산하기 위해 이전 은닉 상태가 먼저 계산되어야 함

h1 계산 → h2 → h3 → …

- 여러 위치의 은닉 상태를 동시에 계산하기 어려움
- 시퀀스 길이가 n이면 순차적으로 거치는 단계도 O(n)만큼 증가함

→ GPU는 많은 연산을 동시에 처리할 수 있지만, RNN의 순차적인 의존성 때문에 이를 충분히 활용하기 어려움

## Attention

현재 표현을 만드는데 필요한 정보를 다른 위치에서 가져오는 방법

기존 RNN 기반 기계 번역에서는 디코더가 인코더의 여러 은닉 상태를 참고하는 데 사용

현재 디코더 상태 → 원문의 각 위치와 관련성 계산 → 필요한 정보를 가중합으로 가져오기

- 원문 전체를 하나의 고정된 벡터에 압축해야하는 병목을 완화함

→ 하나의 시퀀스 내부에 적용 ⇒ Self-Attention

## Self-Atteniton

같은 시퀀스에 있는 단어들이 서로를 참고해 각 단어의 표현을 만드는 방법

각 단어의 입력 표현 → 같은 시퀀스의 단어들 참고 → 문맥이 반영된 새로운 표현

- 멀리 떨어진 단어도 직접 참고할 수 있음
- 각 위치의 출력을 이전 위치의 출력 계산이 끝날 때까지 기다리지 않고 계산할 수 있음

→ 장거리 관계를 더 직접적으로 학습

→ 한 층 안에서 여러 위치의 연산을 병렬로 처리 가능

단, 모든 단어 쌍을 비교하므로 전체 계산량이 일정해지는 것은 아님

## Sequence Order

### Query, Key, Value

어텐션은 Key-Value 저장소에서 필요한 정보를 부드럽게 검색하는 과정으로 이해할 수 있음

일반적인 사전 검색:

> Query 입력 → 정확히 일치하는 Key 검색 → 해당 Value 반환
> 

어텐션:

> Query 입력 → 모든 Key와 관련성 계산 → 관련성에 따라 Value를 가증합
> 

하나만 선택하는 것이 아닌 여러 정보를 서로 다른 비중으로 가져옴

**세 가지 벡터 역할**

- Query(Q): 현재 위치에서 어떤 정보를 찾을지 나타내는 벡터
- Key(K): 각 위치가 어떤 정보와 관련되는지 비교하는 벡터
- Value(V): 실제로 가져와서 합칠 정보를 담은 벡터

셀프 어텐션에서는 같은 입력 표현으로 각각 Q, K, V를 만듦

**입력 벡터 x → 서로 다른 학습 가능한 선형 변환 → Q, K, V**

→ 같은 단어도 정보를 찾는 역할, 검색되는 역할, 정보를 전달하는 역할을 각각 수행

**서로 다른 변환을 사용하는 이유**

Q, K, V를 만드는 가중치 행렬은 서로 다름

→ 어떤 정보를 참고할지 결정하는 기준과 실제로 전달할 내용을 따로 학습할 수 있음

자기 자신을 얼마나 참고할지 또한 학습을 통해 결정됨

→ 같은 단어에서 나온 Query와 Key라고 해서 반드시 높은 점수를 가지는 것은 아님

## 셀프 어텐션 계산 과정

1. **입력 표현 생성**

각 단어를 임베딩 벡터로 변환

단어 → 임베딩 벡터 xi

처음의 단어 임베딩 = 단어 자체의 정보

→ 셀프 어텐션을 통해 다른 단어의 정보를 반영

1. **Query, Key, Value 생성**

각 입력 벡터에 서로 다른 가중치 행렬 적용

xi → qi, ki, vi

이 변환에서 사용하는 매개변수는 학습 과정에서 업데이트

1. **관련성 점수 계산**

현재 위치 i의 Query와 각 위치 j의 Key를 내적

eij = qi * kj

→ i번째 단어가 j번째 단어를 얼마나 참고할지 결정하기 위한 점수

점수는 음수, 0, 양수 등 다양한 값을 가질 수 있음

1. **Softmax 적용**

한 Query에 대해 계산한 점수들에 softmax를 적용

관련성 점수 → softmax → 어텐션 가중치

- 가중치는 0과 1 사이 값 가짐
- 한 Query에 대한 가중치의 합은 1
- 점수가 높은 위치에 더 큰 비중을 부여
1. **Value 가중 합**

각 Value 벡터에 어텐션 가중치를 곱해 더함

→ 현재 단어와 관련된 다른 단어들의 정보를 모은 새로운 표현

Q와 K로 참고할 비중을 결정하고, V에서 실제 정보를 가져오는 방식

## Position Information

기본 셀프 어텐션에는 단어의 순서 정보가 직접 포함되어 있지 않음

예:

> Zuko made his uncle tea.
> 

> His uncle made Zuko tea.
> 

같은 단어들이 사용되었지만, 순서에 따라 누가 차를 만들었는지 달라짐

위치 정보가 없는 경우:

- 입력 순서를 바꿔도 각 단어에 대응하는 출력 표현은 함께 재배열됨
- 단어 순서에 따른 의미 차이를 충분히 표현하기 어려움

**위치 벡터 추가**

각 위치를 나타내는 벡터 pi를 입력 임베딩에 더함

**단어 임베딩 xi + 위치 벡터 pi → 위치 정보가 포함된 입력**

→ 어떤 단어인지와 어느 위치에 있는지를 함께 반영

네트워크 입력에서 위치 정보를 한 번 더하는 방식

**사인 코사인 위치 인코딩**

서로 다른 주기의 사인, 코사인 함수를 이용해 위치 벡터를 만듦

- 각 차원에서 위치에 따라 값이 달라짐
- 차원마다 서로 다른 주기를 사용함
- 위치 벡터를 별도로 학습하지 않고 계산 가능

→ 여러 주기의 값을 조합해 위치를 표현

학습 때보다 긴 위치 벡터도 계산할 수 있지만, 긴 시퀀스에서 좋은 성능을 보장하는 것은 아님

**학습 가능한 위치 임베딩**

각 위치에 대응하는 벡터를 모델의 매개변수로 두고 학습

위치 인덱스 → 위치 벡터 조회 → 단어 임베딩에 더함

단어 임베딩과 비슷한 방식으로 위치 표현을 학습

- 같은 위치에는 문장에 관계 없이 같은 위치 벡터를 사용
- 단어 정보는 입력에 따라 변하지만 위치 벡터는 해당 인덱스에 대응

최대 길이 n까지의 위치 벡터만 준비했다면 그보다 긴 입력은 별도 처리 없이 그대로 사용할 수 없음

## Position-wise Feed-Forward Network

어텐션으로 모은 정보를 각 위치에서 추가로 처리하는 신경망

셀프 어텐션 출력 → 선형 변환 → 비선형 활성화 함수 → 선형 변환

→ 다른 단어에서 가져온 정보를 조합하고 변환

**각 위치를 독립적으로 처리**

각 단어의 벡터에 같은 피드포워드 신경망을 적용

- 위치 사이의 정보를 섞는 역할: 셀프 어텐션
- 각 위치의 벡터를 가공하는 역할: 피드포워드 신경망

→ 병렬 처리가 가능

## Masking

다음 단어를 예측할 때 미래의 정답 정보를 미리 보지 못하도록 제한

예:

> <시작> the chef → who 예측
> 

chef 위치의 표현을 만들 때:

- <시작>, the, chef는 참고 가능
- who는 참고 불가능

→ 정답 미리 보고 예측하는 것 방지

미래 위치 차단하는 방법

모든 위치 쌍의 어텐션 점수를 계산한 후 미래 위치의 점수를 −∞로 설정

**미래 위치의 점수 −∞ → softmax 적용 → 해당 위치의 가중치 0**

→ 미래 단어의 Value가 출력에 반영되지 않음

⇒ Casual Masking

**학습과 생성의 차이**

학습 시: 정답 시퀀스가 주어짐

**전체 정답 시퀀스를 한 칸 이동해 입력 → 마스크 적용 → 여러 위치의 단어를 동시에 예측**

미래 정보를 차단하며 병렬 학습이 가능함

실제 생성:

**다음 단어 생성 → 생성한 단어를 입력에 추가 → 그 다음 단어 생성**

자기회귀 생성은 순차적으로 진행

**패딩 마스크**

길이가 다른 문장들을 하나의 배치로 처리할 때 짧은 문장에 패딩 토큰을 추가

→ 의미 없는 패딩 위치를 참고하지 않도록 마스크를 적용

- 인과적 마스크: 미래 위치를 차단
- 패딩 마스크: 패딩 위치를 차단

## Multi-Head Attention

- 서로 다른 매개변수를 가진 여러 어텐션을 병렬로 수행
- 하나의 단어를 표현할 때 참고해야 하는 관계는 여러 종류일 수 있음

→ 하나의 어텐션 가중치만으로 여러 관계 동시에 표현하는 데 한계

**여러 Head 사용**

각 Head가 독립적인 Q, K, V 변환을 가짐

**같은 입력 → 여러 헤드에서 각 어텐션 계산 → 결과 연결 → 최종 선형 변환**

서로 다른 관점에서 정보 모을 수 있음

각 Head 역할을 사람이 미리 지정하지는 않음

**Head별 차원**

모델 차원이 d, Head 수가 h인 경우 각 Head는 d/h 차원의 벡터를 사용

행렬 형태의 어텐션 계산

모든 위치의 입력 벡터를 하나의 행렬 X로 묶음

X의 크기: n x d

- n: 시퀀스 길이
- d: 모델 차원

Q = XWQ, K = XWK, V = XWV

1. QK^t: 모든 Query–Key 쌍의 점수 계산.
2. Softmax: 각 Query에 대한 가중치 계산.
3. 가중치 행렬 × V: 모든 위치의 Value 가중합 계산.

→ 큰 행렬 연산으로 처리

→ GPU에서 효율적인 병렬 계산 가능

## Scaled Dot-Product Attention

Query와 Key의 내적 점수를 벡터 차원에 따라 조절

차원이 커지면 내적 점수의 변등 폭 커짐

→ softmax 결과가 일부 위치에 지나치게 집중 가능

→ 기울기가 작아져 학습이 어려워질 수 있음

점수 크기 조절

내적 점수를 Query-Key 차원의 제곱근으로 나눔

조정된 점수 = (q*k)/√dₖ

- dk: 해당 head의 query-key 차원
- 일반적인 멀티 해드 구성에서는 dk = d/h

전체 계산: 

**Attention(Q, K, V) = softmax(QKᵀ / √dₖ + M)V**

- 참고 가능한 위치: 0.
- 차단할 위치: −∞.

→ 점수의 크기 조절, 필요한 위치만 참고

## Residual Connection

하위 층의 입력을 반환 결과에 더하는 연결

**출력 = x + F(x)**

- x: 입력
- F(x): 어텐션이나 피드포워드 신경망으로 반환한 결과

→ 입력 정보가 직접 전달되는 경로 제공

→ 역전파 시 기울기가 전달되기 쉬워져 깊은 모델의 학습에 도움

전차 연결의 핵심

모든 정보를 매번 새롭게 변환하는 대신 기존 표현에 필요한 변화를 더함

**기존 표현 유지 + 새롭게 계산한 정보 추가**

→ 여러 블록을 쌓을 때 학습을 더 안정적으로 진행

## Layer Normalization

각 위치의 벡터에서 값의 평균과 분산을 이용해 크기를 정규화

벡터 x → 평균 - → 표준편차에 따라 나눔 → 학습 가능한 크기, 이동 조정

**LayerNorm(x) = γ ⊙ (x − μ) / √(σ² + ε) + β**

- μ: 해당 벡터의 차원들에 대한 평균
- σ²: 해당 벡터의 차원들에 대한 분산
- ε: 0으로 나누는 등의 문제를 방지하는 작은 값
- γ, β: 학습 가능한 조절 매개변수

→ 표현의 크기 변동을 줄여 학습을 안정화

**정규화 범위**

각 토큰의 벡터를 독립적으로 정규화

- 다른 토큰과 평균, 분산을 공유하지 않음
- 배치에 있는 다른 문장과도 평균, 분산을 공유하지 않음

→ 하나의 토큰 벡터 내부 차원들을 기준으로 계산

γ와 β를 적용하기 전 정규화 부분은 평균을 0, 분산을 대략 1로 맞춤

**Add & Norm**

Transformer 구조도에서는 잔차 연결과 총 정규화를 묶어 표시

하위 층 출력 + 입력 → Layer Normalization ⇒ Add & Norm

## Transformer Decoder

이전 토큰을 참고해 다음 토큰을 예측

**Masked Multi-Head Self-Attention → Add & Norm → Feed-Forward Network → Add & Norm**

전체 흐름

입력 토큰 → 토큰 임베딩 + 위치 정보 → 여러 디코더 블록 → 출력 선형층 → 다음 토큰의 확률

## Transformer Encoder

전체 입력의 앞뒤 문맥을 사용해 각 위치의 표현을 만드는 구조

디코더와의 주요 차이:

- 미래 위치를 차단하는 인과적 마스크를 사용하지 않음
- 양방향 문맥을 반영한 표현 생성

## Encoder - Decoder Transformer

입력 시퀀스를 읽고, 이를 바탕으로 출력 시퀀스를 생성

**원문 → 인코더 → 원문의 문맥 표현 → 디코더 → 번역문 생성**

- 원래 Transformer는 이러한 인코더-디코더 구조로 제안
- 언어 모델용 디코더 블록에 크로스 어텐션이 추가

## Cross-Attention

서로 다른 시퀀스 사이에서 정보를 가져오는 어텐션

- Query: 디코더의 현재 표현에서 생성
- Value: 인코더 출력에서 생성
- Key: 인코더 출력에서 생성

디코더의 Query → 원문의 Key들과 비교 → 원문의 Value를 가중합

→ 현재 번역 위치에서 필요한 원문 정보를 가져옴

- 셀프 어텐션: Q, K, V가 같은 시퀀스에서 나옴
- 크로스 어텐션: Q와 K·V가 서로 다른 시퀀스에서 나옴

### 트랜스포머의 장점

**장거리 관계 학습**

멀리 떨어진 단어도 하나의 어텐션 층에서 직접 정보를 주고받음

**병렬 학습**

한 층에서 여러 위치의 표현을 동시에 계산

대규모 사전 학습

많은 데이터와 연산 자원을 활용

### 트랜스포머의 한계

**시퀀스 길이에 따른 제곱 비용**

일반적인 전체 셀프 어텐션은 모든 위치 쌍의 점수를 계산

길이 n의 시퀀스 → n x n 어텐션 점수

**위치 표현과 입력 길이**

학습 가능한 절대 위치 임베딩은 준비된 위치 범위의 제한을 받음

→ 더 긴 입력을 처리하기 위해서 위치 표현이나 모델 구조 등 추가적인 처리가 필요
