# Word Vectors and Language Models

## 1. Word2Vec

단어를 벡터로 표현하는 이유: 컴퓨터가 단어를 처리하려면 숫자로 바꿔야 한다.

단어 벡터는 단어를 여러 숫자로 표현하면서 의미적인 관계도 담으려는 방법이다.

### 1.1 중심 단어와 주변 단어

Word2Vec의 Skip-gram 방식에서는 중심 단어를 보고 주변 단어를 예측한다.

모델은 실제 주변 단어에 높은 확률을 주도록 학습한다.

### 1.2 손실 함수와 학습

손실 함수는 모델의 예측이 얼마나 잘못되었는지 나타내는 값이다.

실제 주변 단어에 낮은 확률을 주면 손실이 커지고, 높은 확률을 주면 손실이 작아진다.

>> 손실을 줄이는 방향으로 단어 벡터를 업데이트한다.

## 2. 경사하강법과 미니배치

### 2.1 경사하강법

기울기: 파라미터가 바뀔 때 손실이 어떻게 변하는지

손실이 줄어드는 방향으로 파라미터를 조금씩 움직인다.

>> 새로운 파라미터 = 기존 파라미터 - 학습률 * 손실의 기울기

학습률: 한 번에 얼마나 크게 수정할 것인가.

### 2.2 데이터를 나누어 학습하는 이유

데이터를 작게 나누어 기울기를 계산하고 자주 업데이트 하는 것이 더 빠르다.

- SGD: 일반적으로 일부 데이터로 기울기를 추정하며 학습하는 방식
- 미니배치: 여러 데이터를 작은 묶음으로 구성해 한 번에 계산하는 방식

작은 묶음의 기울기는 전체 데이터의 기울기와 정확히 같지는 않지만, 계산 부담을 줄이며 학습을 진행할 수 있다.

## 3. Negative Sampling

### 3.1 전체 단어를 비교할 때의 문제

주변 단어의 확률을 Softmax로 계산하려면 어휘에 포함된 모든 단어를 고려해야 한다.

### 3.2 일부 단어만 뽑아서 학습하기

Negative Sampling은 실제로 함께 등장한 단어 쌍과 임의로 뽑은 단어 쌍을 구분하도록 학습하는 방법이다.

ex) 

- 실제 단어 쌍: ‘cat’과 ‘sleep’
- 비교를 위해 뽑은 단어 쌍: ‘cat’과 임의의 다른 단어

실제 단어 쌍에는 높은 점수를 주고, 비교용으로 뽑은 단어 쌍에는 낮은 점수를 주도록 학습한다.

>> 부정 예시: 비교 대상으로 뽑은 단어

### 3.3 장점

모든 단어를 계산하는 대신 일부 단어만 비교하므로 계산량을 줄일 수 있다.

학습 목표를 위해 유용한 벡터를 얻는 방식

## 4. 동시 등장 행렬

### 4.1 동시 등장 정보

단어가 어떤 단어와 함께 등장하는지 기록하면 의미를 파악하는데 도움이 된다.

### 4.2 행렬로 표현하기

행과 열에 단어를 배치하고, 두 단어가 정해진 문맥 범위 안에서 함께 등장한 횟수를 기록 → 동시 등장 행렬

행렬의 한 행을 보면 해당 단어가 다른 단어들과 얼마나 자주 등장했는지 알 수 있다.

## 5. SVD와 차원 축소

차원 축소: 많은 숫자로 표현된 데이터를 더 작은 수의 숫자로 표현

SVD: 행렬의 중요한 구조를 작은 차원을 표현하는데 활용

동시 등장 행렬 + Truncated SVD → 벡터의 차원을 줄임

- 2차원으로 줄인 경우: 단어를 그래프 위의 점으로 표시 가능

차원을 줄이는 과정에서 정보가 손실 → 원래 공간에서의 관계가 그림에 완벽하게 유지되는 것은 아님

## 6. Glove

### 6.1

Glove: 전체 말뭉치에서 얻은 단어의 동시 동작 통계를 이용해 단어 벡터를 학습

단순히 함께 등장한 횟수가 아닌 다른 문맥 단어와 함께 등장하는 비율에 의미 관계가 담겨 있다는 생각을 활용

### 6.2 Word2Vec와 비교

| 구분 | Word2Vec의 Skip-gram | Glove |
| --- | --- | --- |
| 주요 접근 | 중심 단어로 주변 단어를 예측 | 전체 동시 등장 통계를 활용 |
| 학습에 활용하는 정보 | 문장 속 중심 단어와 주변 단어 쌍 | 단어 쌍의 동시 등장 횟수 |
| 결과 | 학습된 단어 벡터 | 학습된 단어 벡터 |

두 방법 모두 단어가 등장하는 문맥 이용하지만 학습 문제를 구성하는 방식이 다르다.

### 8. 단어 벡터 평가

### 8.1 내재적 평가

단어 자체가 의미 관계를 잘 표현하는지 확인하다.

- 의미가 비슷한 단어들의 벡터가 가까운지 확인하기
- 사람이 평가한 단어 유사도와 비교하기
- 단어 사이의 관계를 벡터 연산으로 찾기

>> paris : france = tokyo : japan

벡터를 더하고 빼는 방식으로 관계를 찾을 수 있는지 확인

### 8.2 외재적 평가

단어 벡터를 실제 작업에 사용했을 때 성능이 좋은지 확인한다.

ex) 개체명 인식처럼 문장 속 사람이나 장소를 찾는 직업에 사용

## 9. 여러 뜻을 가진 단어의 문제

단어 하나에 고정된 벡터 하나를 사용하는 경우 두 의미가 섞일 수 있다.

→ 단어 자체 뿐만이 아니라 그 단어가 사용된 문맥도 중요하다.

## 10. 단어 벡터를 신경망에 활용하기

단어 벡터는 신경망의 입력으로 사용할 수 있다.

ex) 특정 단어가 장소 이름인지 판단할 때, 해당 단어와 주변 단어의 벡터를 함께 입력
