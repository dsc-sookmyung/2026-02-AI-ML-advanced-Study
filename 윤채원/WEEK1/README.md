**Lecture 1 — Introduction and Word Vectors**

**핵심 내용**

- **단어를 숫자로 표현하기**
    
    컴퓨터가 단어를 계산에 사용할 수 있도록 숫자 묶음인 **벡터**로 표현한다.
    
- **원핫 벡터의 한계**
    
    단어마다 한 자리만 1로 표시하면 단어를 구분할 수 있지만, 비슷한 뜻인지는 나타내기 어렵다. 예를 들어 hotel과 motel이 관련 있다는 정보를 담지 못한다.
    
- **주변 단어로 의미 파악하기**
    
    비슷한 문맥에서 등장하는 단어는 의미도 비슷할 수 있다는 생각을 이용한다. 이를 바탕으로 단어의 특징을 담은 **단어 임베딩**을 학습한다.
    
- **Word2Vec의 기본 원리**
    
    중심 단어를 보고 주변에 어떤 단어가 등장할지 예측한다. 예측을 잘하도록 벡터 값을 계속 조정하면서 단어 사이의 관계를 배운다.
    
- **확률 계산과 학습**
    
    벡터의 내적으로 점수를 계산하고, **Softmax**로 확률로 바꾼다. 실제 주변 단어에 높은 확률을 주도록 손실함수를 만들고, 미분으로 수정 방향을 구해 벡터를 업데이트한다.
    

**Lecture 2 — Word Vectors and Language Models**

**핵심 내용**

- **Word2Vec의 학습:** 주변에 어떤 단어가 나오는지 예측하면서 단어 벡터를 학습한다. 데이터를 조금씩 나눠 학습하면 한 번에 전체 데이터를 사용하는 것보다 빠르게 가중치를 업데이트할 수 있다.
- **Negative Sampling:** 모든 단어를 비교하면 계산량이 많아진다. 실제 주변 단어와 몇 개의 임의로 뽑은 단어를 비교하는 방식으로 계산량을 줄인다.
- **동시 등장 행렬과 GloVe:** 단어들이 함께 등장하는 정보를 이용해 단어의 관계를 파악한다. SVD는 큰 행렬을 적은 차원으로 줄이는 데 사용하고, GloVe는 전체 데이터의 동시 등장 통계를 이용해 단어 벡터를 학습한다.
- **단어 벡터의 평가와 한계:** 비슷한 단어를 잘 찾는지, 단어 사이의 관계를 잘 표현하는지 등으로 평가한다. 다만 하나의 단어가 여러 뜻을 가지면 벡터 하나로 모든 의미를 표현하기 어렵다.
- **실제 활용:** 단어 벡터를 신경망의 입력으로 사용할 수 있다. 주변 단어를 함께 보면 특정 단어가 사람 이름인지 장소 이름인지 구분하는 데 도움이 된다.

**Lecture 3 — Backpropagation and Neural Networks**

**핵심 내용**

- **신경망의 기본 구조:** 입력에 가중치를 곱하고 편향을 더한 뒤, 활성화 함수를 거쳐 결과를 만든다. 이런 계산을 여러 층으로 연결해 복잡한 관계를 학습한다.
- **활성화 함수:** sigmoid, tanh, ReLU 등이 있다. 신경망이 단순한 선형 계산보다 복잡한 관계를 표현할 수 있도록 해 준다.
- **순전파:** 입력부터 차례대로 계산해 예측값을 만들고, 정답과 얼마나 다른지 손실을 구한다.
- **역전파:** 손실에서 출발해 앞쪽으로 거슬러 올라가며 각 가중치의 기울기를 계산한다. 이때 여러 계산의 미분을 연결하는 **연쇄법칙**을 사용한다.
- **학습 과정:** 역전파로 구한 기울기를 이용해 가중치를 수정한다. 중간 계산 결과를 재사용하면 효율적으로 기울기를 구할 수 있고, 프레임워크의 자동 미분 기능이 이 계산을 처리해 준다.

학습 흐름은 **입력 → 예측 → 손실 계산 → 역전파로 기울기 계산 → 가중치 수정**으로 정리할 수 있다.

**느낀 점**

단어를 숫자로 바꾸는 것뿐 아니라, 주변 단어와의 관계까지 학습할 수 있다는 점이 신기했다. 또 신경망의 학습이 예측의 오차를 계산하고 가중치를 조금씩 수정하는 과정이라는 것을 알게 됐다. 강의에서 배운 단어 벡터를 과제에서 직접 다뤄 보니 개념을 이해하는 데 도움이 됐다.

**어려웠던 점**

Word2Vec과 GloVe가 단어 벡터를 만드는 방식의 차이가 처음에는 헷갈렸다. Softmax와 손실 함수는 역할은 이해했지만, 수식과 미분 과정을 따라가는 것이 어려웠다. 특히 역전파에서 기울기가 전달되는 과정과 행렬의 크기를 맞추는 부분은 간단한 예제로 더 연습해야겠다고 느꼈다.
