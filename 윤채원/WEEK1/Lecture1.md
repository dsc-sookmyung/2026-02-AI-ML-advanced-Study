## 1. 자연어 처리란?

자연어 처리(NLP)는 사람이 사용하는 언어를 컴퓨터가 처리하도록 하는 분야다.

대표 분야

- 문장의 의미를 분석하기
- 질문에 대한 답변 찾기
- 다른 언어로 번역하기
- 문장을 생성하기

## 2. 단어의 의미를 표현하기 어려운 이유

사람 → 경험과 문맥을 이용해 단어의 의미를 이해

컴퓨터 → 단어의 의미가 처음부터 주어지지 않음

- 비슷한 뜻의 단어라도 사용되는 상황이 다름
- 하나의 단어가 여러 의미를 가짐
- 새로운 단어나 표현이 계속 쌓임
- 주변 문맥에 따라 의미가 달라짐

따라서 단어마다 짧은 정의를 붙이는 것만으로는 실제 사용 방식을 모두 표현하기 어렵다.

## 3. 기존의 의미 표현 방법과 한계

### 3.1 WordNet

WordNet은 단어 사이의 관계를 정리한 자원이다.

ex) 비슷한 뜻을 가진 단어들을 연결하기, 어떤 개념이 더 큰 범주에 속하는지 나타내기

이런 정보는 유용하지만 한계도 있다.

- 사람이 직접 정리해야한다.
- 단어의 미묘한 뉘앙스까지 표현하기 어렵다.
- 비슷한 뜻이라고 해서 모든 문장에서 바꿔쓸 수 있는 것은 아니다.

따라서 실제 텍스트에서 단어가 사용되는 모습을 바탕으로 의미를 학습하는 방법을 생각하게 된다.

## 4. One-hot 벡터

### 4.1 원핫 벡터란?

원핫 벡터는 해당 단어의 위치만 1로 표시하고, 나머지는 모두 0으로 표시하는 방법이다.

| 단어 | One-hot 벡터 |
| --- | --- |
| cat | [1, 0, 0, 0] |
| dog | [0, 1, 0, 0] |
| apple | [0, 0, 1, 0] |

각 단어마다 서로 다른 표현을 갖기 때문에 구분하기는 쉽다.

### 4.2 원핫 벡터의 한계

1. 어휘 수가 많아질수록 벡터가 길어진다.
2. 벡터 자체에 의미적인 유사성이 없다.

단어를 구분할 수 있지만 단어끼리 의미가 비슷한지는 표현하지 못한다.

## 5. Distributional Semantics

### 5.1 분포 의미론

분포 의미론은 단어가 어떤 문맥에 등장하는지를 이용해 의미를 파악하는 접근이다.

- 문맥이 비슷하다고 해서 반드시 동의어인 것은 아님

## 6. Word Embedding

### 6.1 단어를 실수 벡터로 표현

단어 벡터는 여러 실수로 표현된다.

>> cat → [0.2, -0.5, 0.8, …]

텍스트를 이용한 학습 과정에서 결정된다.

## 7. Word2Vec

### 7.1

Word2Vec은 주변 단어를 이용해 단어 벡터를 학습하는 방법이다.

중심 단어를 보고 주변 단어를 예측하는 Skip-gram 방식을 중심으로 설명한다.

>> 주변 단어를 잘 예측하도록 학습하면, 단어의 사용 방식이 벡터에 담길 수 있다.

### 7.2 중심 단어와 주변 단어

problems turning into banking crises as …

중심 단어: into

주변 단어: problems, turning, banking, cirses, as

- P(outside | center word)를 높이는 방향으로 학습

### 7.3 Window size

주변 단어를 어디까지 볼지 정하는 범위를 Window size라고 한다.

## 8. Softmax

여러 점수를 확률로 바꾸는 함수이다.

### 8.1 점수와 확률의 차이

내적 점수는 음수일 수도 있고 1보다 클 수도 있다.

따라서 Softmax에서는 여러 점수를 확률 분포로 바꾼다.

1. 중심 단어와 각 주변 단어 후보의 내적을 계산
2. 각 점수에 지수함수를 적용해 양수로 변환
3. 전체 합으로 나누어 확률로 변환

이 확률들을 모두 더하면 1이 된다.

## 9. 목적 함수와 손실 함수

### 9.1

많은 중심 단어와 주변 단어들 쌍에서 이런 예측을 잘하도록 만든다.

### 9.2 로그를 사용하는 이유

확률을 여러 번 곱하는 식에 로그를 적용하면 덧셈 형태로 바꿀 수 있다.

작은 확률을 계속 곱할 때 생기는 수치적 문제를 줄이는 데 도움이 된다.

## 10. 단어 벡터

1. 중심 단어와 실제 주변의 단어를 정한다.
2. 현재 벡터로 주변 단어의 확률을 계산한다.
3. 실제 주변 단어에 대한 손실을 계산한다.
4. 손실을 각 벡터에 대해 미분한다.
5. 손실이 줄어드는 방향으로 벡터를 수정한다.
6. 다른 학습 예시에서도 같은 과정을 반복한다.

## 11. 기울기와 경사하강법

기울기: 파라미터가 조금 바뀔 때 손실이 어떻게 변하는지 나타낸다.

경사하강법: 기울기의 반대 방향으로 파라미터를 수정

Word2Vec에서는 중심 단어 벡터와 주변 단어 벡터들이 학습할 파라미터에 해당한다.

## 12. 미분 결과의 의미

- 모델의 예측 확률로 가중평균한 주변 단어 벡터
- 실제로 관찰된 주변 단어 벡터

→ 모델의 현재 예측과 실제 관찰 사이의 차이가 업데이트에 반영

- 로그 확률의 기울기: 실제 관찰 - 예측의 가중평균
- 음의 로그 손실의 기울기: 예측의 가중평균 - 실제 관찰
