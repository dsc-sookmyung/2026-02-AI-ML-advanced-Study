# Backpropagation and Neural Networks

## 1. 신경망의 기본 구조

### 1.1 입력, 가중치, 편향

신경망의 한 층에는 가중치를 곱하고 편향을 더한다.

z = Wx + b

- z: 입력 벡터
- W: 입력을 변환하는 가중치 행렬
- b: 편향
- z: 계산 결과

활성화 함수

h = f(z)

h는 다음 층으로 전달되는 값이다.

### 1.2 은닉층

은닉층: 입력과 최종 출력 사이에 있는 층

- 입력을 다른 표현으로 바꿈
- 여러 층을 연결해 앞에서 계산한 결과를 다음 층이 다시 활용 가능
- 단어와 문맥의 정보를 조합해 분류에 필요한 특징을 학습

## 2. 활성화 함수

### 2.1 활성화 함수가 필요한 이유

가중치를 곱하고 편향을 더하는 계산만 여러번 하면, 전체 계산을 하나의 선형 변환과 편향으로 합칠 수 있다.

→ 층을 쌓는 것만으로는 복잡한 관계를 표현하는데 한계가 있다.

→ 비선형 함수를 사용하면 신경망이 더 복잡한 관계를 표현할 수 있다.

### 2.2 대표적인 활성화 함수

- Sigmoid: 값을 0과 1 사이로 변환
- tanh: 값을 -1과 1로 변환
- ReLU: 음수는 0으로, 양수는 0으로 전달

활성화 함수에 따라 출력 범위, 기울기의 특성이 달라진다.

## 3. 순전파

입력 → 출력 방향의 계산 과정

1. 입력 벡터를 넣기
2. 가중치를 곱하고 편향을 더하기
3. 활성화 함수 적용
4. 다음 층에서 계산
5. 예측값 생성
6. 예측값과 정답을 비교해 손실 구하기

이 과정에서 계산한 중간값은 역전파에서도 사용된다.

## 4. 손실 함수

모델의 예측이 정답과 얼마나 다른지 나타낸다.

학습 목표: 손실을 줄이는 것

손실값만 알면 어떤 가중치를 얼마나 바꿔야 하는지 알 수 없다.

→ 각 파라미터가 손실에 어떤 영향을 주는지 기울기를 계산

## 5. 기울기의 의미

손실의 기울기: 가중치가 조금 변화했을 때 손실이 어떻게 변하는지를 나타낸다.

- 기울기가 양수: 가중치가 증가하면 손실이 증가하는 방향
- 기울기가 음수: 가중치가 증가하면 손실이 감소하는 방향

경사하강법에서는 기울기의 반대 방향으로 파라미터를 수정한다.

## 6. 연쇄 법칙

### 6.1 여러 계산이 연결된 경우

신경망에서는 하나의 계산 결과가 다른 계산의 입력이 된다.

>> x → z → L

x가 바뀌면 z가 바뀌고, z가 바뀌면 L이 바뀐다

이 때 x가 L에 미치는 영향을 중간 단계의 미분을 연결해 계산

$$
\frac{dL}{dx}
=
\frac{dL}{dz}
\frac{dz}{dx}
$$

### 6.2 간단한 예시

z = 2x

L = z^2

각 단계의 미분

- z의 L에 대한 미분: 2z
- x에 대한 z의 미분: 2

$$
\frac{dL}{dx} = 2z \times 2 = 4z
$$

z= 2x를 대입하면 8x가 된다.

## 7. 계산 그래프

계산 그래프는 복잡한 수식을 작은 연산들로 나누어 연결한다.

h = f(wx + b)

이를 다음 연산으로 나눈다.

1. w와 x를 곱한다.
2. b를 더한다.
3. 활성화 함수 f를 적용한다.

각 연산을 연결해두면 순전파에서는 값을 계산, 역전파에서는 기울기를 전달할 수 있다.

## 8. 역전파

### 8.1 기본 개념

출력 쪽에서 입력 쪽으로 거슬러 올라가며 기울기를 계산하는 방법이다.

각 연산에서는 다음 두 가지를 결합한다.

- 뒤쪽에서 전달된 기울기
- 현재 연산 자체의 미분값

>> 앞쪽으로 전달할 기울기 = 뒤에서 받은 기울기 x 현재 연산의 미분값

### 8.2 역전파와 업데이트의 차이

역전파: 기울기를 계산하느 ㄴ과정

계산한 기울기로 파라미터를 실제로 바꾸는 것 → 경사 하강법

## 9. 여러 경로로 연결된 경우

하나의 값이 여러 계산에 사용될 수 있다.

해당 값이 여러 경로를 통해 최종 손실에 영향을 준다.

따라서 역전파 할 때는 각 경로에서 전달된 기울기를 더한다.

ex) 

x가 두 경로로 손실에 영향 → x의 전체 기울기 = 첫 번째 경로의 기여 + 두 번째 경로의 기여

## 10. 벡터와 행렬의 미분

실제 신경망의 입력, 가중치는 대부분 벡터나 행렬이다.

숫자 하나를 미분할 때 모양과 크기를 주의해야 한다.

ex) z = Wx + b

- x: n차원 벡터
- W: m x n 행렬
- b: m차원 벡터
- z: m차원 벡터

여러 출력값을 여러 입력값에 대해 미분한 정보를 모은 행렬을 야코비안이라고 한다.

역전파에서는 미분 관계를 이용하지만 전체 야코비안을 직접 만들지 않고 필요한 계산만 수행할 수도 있다.

스칼라 손실을 각 파라미터에 대해 미분한 결과는 해당 파라미터와 같은 모양으로 정리할 수 있다.

## 11. 역전파가 효율적인 이유

각 파라미터의 기울기를 처음부터 따로 계산하면 중복되는 계산이 많다

역전파는 뒤쪽에서 구한 기울기, 순전파에서 저장한 중간값을 재사용한다.

→ 많은 파라미터의 기울기를 효율적으로 계산 가능

## 12. 자동 미분

딥러닝 프레임워크 : 연산 사이의 관계를 이용 → 기울기 자동 계산

유의할 점

- 손실이 어떤 계산으로 만들어지는지
- 어떤 파라미터가 학습되는지
- 데이터가 어떤 크기로 전달되는지
- 기울기가 어디까지 연결되는지
