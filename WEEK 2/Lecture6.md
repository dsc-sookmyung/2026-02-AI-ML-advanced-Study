## 순환 신경망(Recurrent Neural Network)

순서가 있는 입력을 처리하는 신경망 아키텍처.

**어떤 길이의 순차 입력 → 각 단계에서 동일한 가중치 적용 → 필요에 따라 각 단계에서 출력 생성**

- 다양한 종류의 시퀀스에 여러 용도로 사용할 수 있음.

## 언어 모델링(Language Modeling)

자연어 처리 작업의 전통적인 구성 요소.

텍스트를 생성하거나, 하나의 텍스트가 나올 가능성을 추정하는 작업과 관련됨.

사용할 수 있는 모델:

- 순환 신경망(RNN)
- 트랜스포머
- n-gram 언어 모델

## 언어 모델 평가

**실제 텍스트에 모델이 얼마나 높은 확률을 부여하는지** 평가하는 것.

- 평가 대상: 인간이 작성한 텍스트
- 학습에 사용하지 않은 새로운 텍스트를 사용

**새로운 텍스트 → 언어 모델에 입력 → 각 위치의 실제 단어가 나올 확률 예측**

예측을 잘할수록 더 나은 언어 모델이라고 볼 수 있음.

→ 인간이 작성한 텍스트를 더 정확하게 예측하기 때문.

## Perplexity

언어 모델의 예측 성능을 측정하는 표준적인 지표: **퍼플렉시티(Perplexity)**

각 정답 단어에 부여한 확률의 **역수를 기하평균한 값**.

예: 정답에 준 확률이 `0.002`라면 그 역수는 `500`.

계산 과정:

1. 텍스트의 각 위치에서 정답 단어에 부여한 확률을 구함.
2. 그 확률들의 역수를 곱함.
3. 단어 개수에 맞춰 기하평균을 구함.

### 음의 로그 우도와 교차 엔트로피

**퍼플렉시티 = 교차 엔트로피를 지수화한 값**

즉, **단어당 평균 음의 로그 우도를 지수화하면 퍼플렉시티**가 됨.

!image.png

### 로그와 지수의 밑

- 전통적으로는 밑이 2인 로그를 사용.
- 자연로그를 사용하는 경우도 많음.

로그의 밑에 따라 교차 엔트로피의 숫자는 달라지지만, **같은 밑으로 지수화하면 퍼플렉시티는 동일함.**

### 퍼플렉시티의 해석

교차 엔트로피를 지수화하면, 예측의 어려움을 **균일한 선택지의 개수**처럼 해석할 수 있음.

예:

> 퍼플렉시티가 64라면, 평균적인 예측 불확실성이 64개의 선택지에 균등한 확률을 주는 경우와 대응함.
> 

64면체 주사위에서 특정 면을 맞히는 상황에 비유할 수 있음.

**퍼플렉시티가 낮을수록 언어 모델의 예측 성능이 좋음.**

단, 서로 비교하려면 평가 데이터와 토큰화 등의 조건이 같아야 함.

### 신경 언어 모델의 발전 과정

기존 방법:

- n-gram language model
- 스무딩(smoothing)
- 백오프(backoff)

대표적인 방법:

- **Interpolated Kneser–Ney smoothing**
- 드물거나 관측되지 않은 표현의 확률을 보정하는 방식

이후 RNN이 도입되면서 다음 단어를 예측하는 성능이 개선됨.

강의에서 언급된 예에서는 최대 엔트로피 모델과 RNN을 결합해 약 51의 퍼플렉시티를 얻음.

## LSTM 모델

강의에서는 LSTM을 통해 퍼플렉시티가 43, 30 등으로 낮아진 결과를 소개함.

- 퍼플렉시티가 **절반으로 줄면**, 교차 엔트로피는 단어당 약 1비트 감소.
- 이는 언어 모델링에서 의미 있는 성능 개선을 나타냄.

강의에서는 더 발전한 모델이 한 자릿수 퍼플렉시티를 얻는 경우도 언급함.

→ 실제 단어에 더 높은 확률을 부여할 수 있다는 의미.

※ 구체적인 수치는 평가 조건에 따라 달라짐.

## RNN 문제점

- 기울기 소실(Vanishing Gradients)
- 기울기 폭발(Exploding Gradients)

단어를 예측할 때, 실제 정답 단어에 부여한 확률을 이용해 **음의 로그 우도 손실**을 계산함.

→ 시퀀스를 따라 역전파하며 기울기를 계산.

!image.png

### 기울기가 작아지거나 커지는 이유

각 시간 단계의 손실을 역전파할 때 **연쇄 법칙**이 적용됨.

→ 여러 시점의 편미분 값을 연속해서 곱하게 됨.

시퀀스가 길수록 곱하는 횟수도 많아짐.

- 작은 값이 반복해서 곱해지면 → 기울기가 점점 작아짐.
- 큰 값이 반복해서 곱해지면 → 기울기가 점점 커짐.

비선형 활성화 함수가 항등 함수라고 가정하면, 은닉 상태 사이의 미분에는 순환 가중치 행렬 Wh가 등장함.

→ 여러 시점을 거슬러 올라가면 Wh의 거듭제곱이 나타남.

선형적인 경우, 고유값의 절댓값을 통해 다음과 같은 경향을 이해할 수 있음.

- 모든 고유값의 절댓값이 1보다 작으면 → 거듭제곱이 커질수록 값이 줄어드는 경향.
- 절댓값이 1보다 큰 고유값이 있으면 → 해당 방향의 값이 커질 수 있음.

실제 RNN에서는 활성화 함수의 미분도 함께 영향을 줌.

### 기울기 소실의 문제점

멀리 있는 시점에서 전달되는 기울기가 가까운 시점의 기울기보다 훨씬 작아짐.

→ 매개변수 업데이트가 주로 가까운 시점의 손실에 영향을 받음.

→ 먼 시점의 정보와 현재 예측 사이의 관계를 학습하기 어려워짐.

언어 모델링에서는 오래전 문맥이 필요한 경우가 많음.

따라서 장기적인 관계를 학습하지 못하면, 테스트 단계에서도 해당 문맥을 활용해 제대로 예측하기 어려움.

### 기울기 폭발의 문제점

기울기가 매우 커지면 매개변수 업데이트 값도 커짐.

- 한 번에 지나치게 큰 업데이트가 발생할 수 있음.
- 손실을 줄이는 방향으로 안정적으로 학습하기 어려워짐.
- `Inf`나 `NaN`이 발생할 수 있음.

### 기울기 폭발의 해결 방법

**기울기 잘라내기(Gradient clipping)**

→ 너무 큰 기울기를 제한해 업데이트를 안정화함.

## Gradient Clipping

기울기 벡터의 노름(norm)을 계산함.

노름이 정해진 임계값보다 크면:

1. 기울기의 크기를 줄임.
2. 줄어든 기울기를 이용해 매개변수를 업데이트함.

**방향은 유지하고, 크기만 조절하는 방식.**

### 기울기 소실 문제와 메모리

기본 RNN은 다음 단계로 넘어갈 때 은닉 상태가 계속 변형됨.

- 이전 은닉 상태에 행렬을 곱함.
- 새로운 입력을 반영함.
- 비선형 함수를 적용함.

→ 정보를 여러 시점에 걸쳐 그대로 보존하기 어려움.

따라서 **정보를 쉽게 보존할 수 있는 별도의 메모리를 가진 RNN**을 설계함.

단순히 `tanh`, `sigmoid`를 사용하는 것만으로는 이 문제가 해결되지 않음.

→ **LSTM(Long Short-Term Memory)** 등장.

→ 더 오래전의 문맥을 활용하기 쉬워짐.

## LSTM

입력 시퀀스를 처리하며, 내부에 두 종류의 상태를 가짐.

- **은닉 상태(hidden state)**
- **셀 상태(cell state)**

게이트를 도입해 두 상태가 업데이트되는 방식을 조절함.

### 게이트(Gate)

0과 1 사이의 값을 가지는 벡터.

- 0에 가까우면 → 정보를 거의 차단.
- 1에 가까우면 → 정보를 거의 통과.
- 중간값이면 → 정보를 일부 통과.

→ 정보의 흐름을 제어함.

게이트는 현재 입력과 이전 은닉 상태를 이용해 계산하며, sigmoid 함수를 통해 0과 1 사이의 값을 얻음.

### 세 가지 게이트

1. **망각 게이트**
    - 이전 셀 상태의 정보를 얼마나 유지할지 결정.
2. **입력 게이트**
    - 새로운 후보 정보를 셀 상태에 얼마나 저장할지 결정.
3. **출력 게이트**
    - 셀에 저장된 정보를 은닉 상태에 얼마나 전달할지 결정.

### 셀 상태 업데이트

새로운 후보 정보는 다음 요소를 이용해 계산함.

- 이전 은닉 상태에 가중치 행렬을 곱한 값
- 현재 입력에 가중치 행렬을 곱한 값
- 바이어스

셀 상태는 다음 두 정보를 합쳐 업데이트함.

- **이전 셀 상태 × 망각 게이트**
- **새로운 후보 정보 × 입력 게이트**

새로운 은닉 상태는 셀 상태에 `tanh`를 적용하고, 출력 게이트를 곱해 계산함.

현재 문맥에서 다음 단어를 예측하는 데 필요한 정보를 메모리에 저장하도록 학습함.

게이트, 셀 상태, 은닉 상태는 동일한 길이의 벡터를 사용함.

!image.png

### 상태의 전달

셀 상태 Ct와 은닉 상태 Ht가 다음 시점으로 전달됨.

- Ct: 정보를 보존하는 메모리 역할.
- Ht: 다음 시점의 게이트와 새로운 후보 정보 계산에 사용.

게이트는 별도의 임계값으로 기억과 망각을 결정하는 것이 아니라, **학습된 연속적인 값으로 정보의 양을 조절함.**

### LSTM의 핵심

**과거 기억 중 필요한 부분을 유지하고, 새로운 정보를 추가하는 것.**

특정 차원에서 망각 게이트가 1, 입력 게이트가 0이라면:

→ 기존 셀 상태의 정보를 그대로 유지할 수 있음.

이 구조 덕분에 여러 시간 단계에 걸쳐 정보를 보존하기 쉬워짐.

### 깊은 신경망에서의 연결

깊은 신경망에서도 기울기가 사라지면 하위 레이어에 학습 신호가 충분히 전달되지 않음.

→ 하위 레이어의 매개변수가 제대로 업데이트되기 어려움.

이를 완화하기 위해 더 직접적인 연결을 사용함.

- **ResNet**
    - 입력을 항등 경로로 전달하고, 레이어의 출력에 더함.
    - 잔차 연결을 사용.
- **DenseNet**
    - 각 층의 출력을 뒤의 층들에 직접 연결해 이어 붙임.
- **Highway Network**
    - 게이트를 이용해 입력을 유지하는 경로와 변환하는 경로의 비중을 조절.
    - LSTM의 게이트 개념과 관련된 구조.

### LSTM과 RNN의 활용

시퀀스 처리와 관련된 다양한 작업에 사용할 수 있음.

예: 감정 분류

**전체 문장 입력 → 최종 은닉 상태 → 분류 레이어 → 긍정·부정 판별**

다른 정보를 바탕으로 텍스트를 생성하는 데도 사용 가능.

- 음성 인식
- 요약
- 기계 번역

입력 정보를 조건으로 네트워크가 텍스트를 생성함.

→ **조건부 언어 모델(Conditional Language Model)**

## 양방향 LSTM

앞의 내용뿐 아니라 뒤의 내용도 함께 고려하기 위한 구조.

- 순방향 LSTM: 앞에서 뒤로 처리.
- 역방향 LSTM: 뒤에서 앞으로 처리.

두 방향에서 얻은 벡터를 연결함.

→ 각 단어에 대해 **앞뒤 문맥을 모두 반영한 표현**을 생성.

단, 전체 입력을 볼 수 있는 작업에 사용하며, 미래 단어를 알 수 없는 다음 단어 생성에는 그대로 적용할 수 없음.

### 스택형 RNN(Stacked RNN)

여러 층의 RNN을 쌓은 구조.

- 아래층의 은닉 상태를 위층의 입력으로 사용.
- 여러 단계의 변환을 통해 더 복잡한 표현을 학습.

강의에서는 비교적 적은 수의 LSTM 층을 사용하는 사례와, 더 깊은 Transformer 구조를 비교함.

문맥에 따라 같은 단어의 해석이나 번역이 달라지는 등의 복잡한 관계를 학습하는 데 활용됨.

### 신경망 기계 번역

번역을 **하나의 end-to-end 신경망 시스템**으로 구성함.

**최종 손실 계산 → 시스템 전체에 역전파 → 전체 매개변수 업데이트**

→ 모든 구성 요소를 최종 번역 작업에 맞춰 함께 학습할 수 있음.

!image.png

### Sequence-to-Sequence

강의에서 소개하는 기본 구조는 두 개의 RNN/LSTM을 사용함.

1. **인코더:** 원문을 읽고 정보를 표현.
2. **디코더:** 원문 정보를 바탕으로 번역문 생성.

인코더는 원문을 순서대로 처리하며 은닉 상태를 구축함.

→ 인코더의 최종 상태를 이용해 디코더의 초기 상태를 구성.

인코더와 디코더는 서로 다른 매개변수를 가지지만, **하나의 번역 손실을 통해 함께 학습함.**

디코더의 학습 과정:

1. 각 위치의 다음 단어를 예측.
2. 실제 정답 단어에 부여한 확률로 손실 계산.
3. 전체 위치의 평균 손실 계산.
4. 기울기를 네트워크 전체에 역전파.
5. 인코더와 디코더의 매개변수를 업데이트.

→ **End-to-end 학습 방식**

Seq2Seq는 입력 시퀀스를 출력 시퀀스로 변환하는 인코더–디코더 모델의 일반적인 개념임.

## 조건부 언어 모델

입력 X가 주어졌을 때 출력 Y가 나올 확률을 모델링함.

**P(Y|X)**

→ 입력 정보에 조건화된 텍스트를 생성하는 것.

기계 번역에서는 대규모 **병렬 코퍼스**, 즉 원문과 번역문이 쌍으로 구성된 데이터를 사용함.
