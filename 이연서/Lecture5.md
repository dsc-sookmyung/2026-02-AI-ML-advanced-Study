## 2. 언어 모델의 기본

- 언어 모델 = 앞에 나온 단어들을 보고 다음 단어의 확률 분포를 예측하는 모델
- 확률 분포 = 각 후보가 나올 가능성을 숫자로 나타낸 것

### 문장 전체의 확률

언어 모델은 단어들의 확률을 곱해서 문장 전체에도 확률을 부여할 수 있다.

예시: 나는 밥을 먹었다

![스크린샷 2026-10-06 오후 2.43.52.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_2.43.52.png)

⇒ 문장의 순서대로 **지금까지 나온 단어들을 조건으로 다음 단어의 확률을 구해 곱**한다

+) 조건부 확률 (`P(결과|조건)`)

![스크린샷 2026-10-06 오후 2.44.53.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_2.44.53.png)

### 정리

- 언어모델: 앞에 나온 단어들을 보고 다음 단어의 확률 분포를 에측
- 조건부 확률 P(다음 단어 | 문맥): 오른쪽은 이미 주어진 문맥, 왼쪽은 예측할 단어
- 확률의 연쇄 법칙: 각 단어가 앞선 문맥에서 나올 확률을 차례로 곱하면, 단어열 전체의 확률을 얻는다
- 일상 속 활용: 휴대전화의 입력 예측, 검색어 자동완성

## 3. n-gram 언어 모델

### n-gram

`n-gram` = 연속된 단어 n개로 이루어진 묶음

n = 묶음에 들어가는 단어 수

ex. 나는 오늘 커피를 마셨다

| 종류 | 연속된 단어 묶음 |
| --- | --- |
| 1-gram | “나는”, “오늘”, “커피를”, “마셨다” |
| 2-gram | “나는 오늘”, “오늘 커피를”, “커피를 마셨다” |
| 3-gram | “나는 오늘 커피를”, “오늘 커피를 마셨다” |

묶음은 한 단어씩 이동하면서 겹칠 수 있음

n-gram 언어 모델이 사용하는 문맥 길이

### 마르코프 가정

- n-gram 언어 모델은 다음 단어를 예측할 때 바로 앞의 n-1개 단어만 사용한다.
- 더 앞의 단어는 직접 고려하지 않는다는 가정이며 이를 마르코프 가정이라 부른다

+ n-1개인 이유 = `문맥과 예측할 단어를 합쳐 n개짜리 묶음`이 되기 때문

| 모델 | 사용하는 문맥 | 예측할 단어 | 합계 |
| --- | --- | --- | --- |
| 2-gram | 앞의 1개 | 다음 1개 | 2개 |
| 3-gram | 앞의 2개 | 다음 1개 | 3개 |
| 4-gram | 앞의 3개 | 다음 1개 | 4개 |

### 최대우도추정(MLE)

: 등장 횟수 기반 계산 개념 (Maximum Likelihood Estimation)

MLE = 관측된 비율을 확률로 사용하는 방법

![스크린샷 2026-10-06 오후 5.04.18.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_5.04.18.png)

ex. 문맥이 등장한 100번 중 다음 단어가 ‘샀다’인 경우가 15번이라면, 확률은 얼마로 추정할 것인가?

### 데이터 희소성(sparsity)

: 가능한 단어 조합에 비해 관측된 예가 부족한 문제 (ex. 특정 조합을 한번도 보지 못해 확률을 0으로 추정하는 경우)

예시: “오늘 아침에 커피를”은 100번 등장했지만, 그 뒤에 ‘쏟았다’가 나온 적은 없다면

![스크린샷 2026-10-06 오후 5.07.14.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_5.07.14.png)

그러나 오늘 아침에 커피를 쏟았다 << 라는 이 표현은 충분히 가능

따라서 데이터에서 못봤다는 이유만으로 불가능하다고 취급하는 것이 문제!!

⇒ 이를 완화하기 위한 방법이 바로 평활화(`smoothing`)이다

### 백오프(backoff)

: 다음 단어와의 조합뿐 아니라, 문맥 자체를 한번도 보지 못한 경우

4-gram 모델에서 “오늘 아침에 커피를”이라는 문맥의 등장 횟수가 0이라면 분모가 0이 되어 비율 계산이 불가능

⇒ 이때 **더 짧은 문맥으로 물러나 예측하는 방법인 백오프**를 사용하면 됨

이것이 바로 희소성 문제의 >> 부분적인 해결책 <<

### 문맥 길이의 상충 관계(trade-off)

n을 키우면 더 긴 문맥을 사용할 수 있지만 2가지 문제가 존재

**n을 키울 경우 발생할 수 있는 effect**

1. 더 긴 문맥을 사용하기 때문에 → 예측에 필요한 단서를 더 많이 고려할 수 있음
2. 가능한 단어 조합이 늘어남 → 각 **조합의 관측 예가 부족**해져 희소성 강화
3. 관측한 n-gram의 등장 횟수를 저장 → 저장 공간 부담이 커짐

한 쪽의 이점을 얻으면 다른 쪽의 부담이 커짐 ⇒ 상충 관계

### 샘플링을 통한 텍스트 생성

언어 모델은 다음 단어의 확률을 계산한 뒤, 그 분포에서 단어를 샘플링(sampling)할 수 있다 (샘플링 = 확률에 따라 무작위로 하나를 뽑는 것)

| 현재 문맥 | 다음 단어 후보와 확률 | 뽑힌 단어 |
| --- | --- | --- |
| 나는 오늘 | 커피를 0.6, 밥을 0.4 | 커피를 |
| 오늘 커피를 | 마셨다 0.8, 쏟았다 0.2 | 쏟았다 |

뽑힌 단어를 뒤에 붙이고, **최근 두 단어를 새 문맥으로 삼아 반복**하면 “나는 오늘 커피를 쏟았다”가 만들어진다

확률이 높은 단어가 더 자주 뽑히지만 **항상 그 단어만 뽑히는 것은 아니다**

### 정리

- **n-gram:** 연속된 단어 n개의 묶음입니다.
- **마르코프 가정:** 다음 단어를 예측할 때 바로 앞의 n-1개 단어만 사용합니다.
- **최대우도추정(MLE):** 등장 횟수의 비율로 확률을 추정합니다.
- **희소성:** 조합을 못 봤다면 평활화로, 문맥 자체를 못 봤다면 백오프로 완화할 수 있습니다.
- **텍스트 생성:** 다음 단어를 샘플링하고 문맥을 갱신하며 반복합니다.

## 4. 신경망 언어 모델에서 RNN으로

### 고정 윈도우 신경망 언어 모델

: 최근 단어 몇 개를 입력받아 다음 단어를 예측하는 신경망

`fixed window`: **정해진 개수의 최근 단어만** 보는 범위

**처리 과정**

1. 세 단어를 각각 임베딩 벡터로 변경
2. 벡터 세개를 이어 붙여 입력 벡터 하나를 생성
3. 은닉층과 softmax를 거쳐 ‘마셨다’, ‘쏟았다’ 등 다음 단어 후보의 확률을 출력

n-gram 모델이 등장 횟수를 세어 확률을 구했다면, 이 모델은 **학습한 임베딩과 가중치로 계산**해서 확률을 구함!!

### RNN

: 단어를 순서대로 처리하면서 매 단계에 같은 가중치를 반복해서 사용하는 모델

고정 윈도우 모델처럼 여러 단어의 임베딩을 전부 이어 붙이는 대신, 매 단계에서 아래의 2가지를 사용한다

- 현재 단어의 임베딩
- 이전 은닉 상태(= 앞에서 읽는 내용의 정보를 담은 고정 차원의 벡터)

**처리 흐름**

이전 은닉 상태 + 현재 단어의 임베딩 → 새 은닉 상태

여기서 ‘+’ 의 의미 = 두 정보를 함께 사용한다 ! ! ! (숫자 덧셈 아님)

문장이 길어지면 처리 단계는 늘어나지만, 같은 가중치를 재사용하므로 문장 길이에 따라 파라미터 수가 늘어나지는 않음 (계산 단계가 늘어나는 거지 파라미터가 늘어나는 게 아님)

### 은닉 상태(hidden state)

RNN은 **현재 단어의 임베딩과 이전 은닉 상태로 새 은닉 상태를 계산**

### RNN의 장점과 한계

RNN은 같은 가중치를 반복해서 사용하므로 입력이 길어져도 파라미터 수가 늘어나지 X

⇒ 이전 은닉 상태를 전달하기 때문에 이론적으로는 머얼리 앞에 나온 정보도 활용 가능

한계

1. 순서대로 계산해야 함 → 새 은닉 상태를 계산하려면 이전 은닉 상태가 필요
2. 먼 과거의 정보를 활용하기 어려움
    
    → 정보를 계속 갱신하는 과정과 학습상의 문제 때문에 오래전 단서를 잘 활용하지 못할 수 있음
    

### 정리

- 고정 윈도 모델은 최근 단어들의 임베딩을 이어 붙인다
- RNN은 **현재 단어의 임베딩과 이전 은닉 상태**로 새 은닉 상태를 만들고, 그 상태에서 다음 단어의 확률을 계산

## 5. RNN 학습 & 생성 & 평가

### RNN 언어 모델의 학습 목표

학습할 때는 문장의 각 위치에서 실제 다음 단어를 예측하고, 그 정답에 얼마나 높은 확률을 줬는지 평가

사용 Loss = cross-entropy (교차 엔트로피)

![스크린샷 2026-10-06 오후 7.25.55.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_7.25.55.png)

⇒ 여기서도 마찬가지로 정답 확률이 높아질수록 손실 값은 작아진다

### 교사 강요 (teacher forcing)

학습 중에는 모델이 예측한 단어 대신, **데이터에 있는 실제 정답 단어를 다음 단계의 입력**으로 넣음 (예측이 틀려도 정답 문맥으로 학습을 이어가는 것이 가능)

**보충 예시:** 학습 문장이 “나는 커피를 마셨다”라고 합시다.

1. ‘나는’을 입력받아 다음 단어를 예측합니다.
2. 모델이 ‘밥을’에 가장 높은 확률을 줬더라도, 정답인 ‘커피를’의 확률로 손실을 계산합니다.
3. 다음 단계에는 실제 단어 ‘커피를’를 입력해 ‘마셨다’를 예측합니다.

⇒ 이렇게 학습 시 다음 단계에서도 정답 문맥을 기준으로 학습이 가능하다 (앞 단계의 은닉 상태는 그대로 이어서 사용)

### 여러 단계의 손실 합치기

각 위치에서 계산한 손실을 평균 내어 전체 학습 손실을 구한다 !!!

![스크린샷 2026-10-06 오후 7.31.13.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_7.31.13.png)

⇒ 한 단계만 잘 맞히는 것이 아니라, **여러 위치에서 정답 단어에 높은 확률을 주도록 학습**하는 것!!

+) 실제로는 전체 학습 데이터를 한번에 처리 시 메모리 부담이 크기 때문에, 실제로는 문장들을 작은 묶음인 batch로 나누어 손실과 기울기를 계산한 뒤 가중치를 업데이트 한다

### 시간축 역전파(BPTT, Backpropagation Through Time)

RNN도 손실에서 시작해 거꾸로 기울기를 계산한다

→ 다만 은닉 상태가 앞선 단계와 연결되어 있음 ⇒ 단어를 처리한 순서를 거슬러 역전파

> 시간의 의미 = 단어를 처리하는 단계
> 

![스크린샷 2026-10-06 오후 7.35.26.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_7.35.26.png)

⇒ 역전파에서는 위 연결을 거꾸로 따라가며, 앞선 계산이 손실에 얼마나 영향을 줬는지 구함

같은 가중치를 여러 단게에서 사용했기 때문에, 각 사용 지점에서 계산된 기울기를 더해야 함 (모두 같은 파라미터(=가중치)에 대한 기여이기 때문에)

### 공유 가중치의 기울기

RNN의 구조를 펼쳐보면 각 단계에 가중치가 따로 있는 것처럼 보이는데, 실제로 같은 가중치임 ⇒ 따라서 하나의 가중치를 바꾸면 모든 지점의 계산이 바뀐다

![스크린샷 2026-10-06 오후 7.40.34.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_7.40.34.png)

### 절단된 시간축 역전파(truncated BPTT)

긴 시퀀스의 모든 단게를 거슬러 역전파하면 계산과 메모리 부담이 커짐 → 실제 학습에서는 일정 단계까지만 거슬러 기울기를 계산하기도 한다

⇒ 이게 바로 truncated BPTT

| 구분 | 처리 |
| --- | --- |
| 앞으로 읽으며 계산 | 이전 은닉 상태를 계속 전달할 수 있음 |
| 거꾸로 학습 신호 전달 | **정해진 범위에서 끊음** |

역전파를 끊는다고 그 지점에서 은닉 상태를 반드시 초기화하는 것은 아니다!!!!

### RNN 언어 모델의 텍스트 생성

문장을 생성할 때는 **다음 단어를 샘플링**하고, **뽑힌 단어를 다음 단계의 입력**으로 넣는다

ㄴ 위의 과정을 반복

![스크린샷 2026-10-06 오후 7.43.57.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_7.43.57.png)

앞의 teacher forcing과 입력의 출처가 다름

| 상황 | 다음 단계에 넣는 단어 |
| --- | --- |
| 학습 — teacher forcing | 데이터의 **실제 정답** 단어 |
| 생성 — 반복 샘플링 | 모델의 **확률 분포에서 뽑힌** 단어 |

생성 시에는 이어질 정답 문장이 주어져 있지 않으므로, **자신이 생성한 문장을 바탕으로 계속 예측**하는 것

### 퍼플렉서티(perplexity)

: 언어 모델을 평가하는 지표 / **낮을수록 좋음**

**자연로그로 계산한 평균 교차 엔트로피 손실 J와의 관계**

![스크린샷 2026-10-06 오후 7.46.59.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_7.46.59.png)

위의 예시 해석 = 동일한 확률을 가진 후보 4개 사이에서 예측하는 정도의 불확실성으로 해석 가능 (실제 어휘가 4개라는 것은 아니다)

### 정리

- **교차 엔트로피:** 실제 다음 단어에 준 확률로 손실을 계산합니다.
- **Teacher forcing:** 학습에서는 실제 정답 단어를 다음 입력으로 사용합니다.
- **BPTT:** 처리 순서를 거슬러 기울기를 계산하고, 공유 가중치의 기울기 기여를 합칩니다.
- **Truncated BPTT:** 기울기를 거슬러 전달하는 범위를 제한합니다.
- **텍스트 생성:** 샘플링한 단어를 다음 입력으로 사용합니다.
- **퍼플렉서티:** 같은 평가 조건에서 낮을수록 좋습니다.

## 6. RNN의 학습 문제

### 기울기 소실(vanishing gradient)

역전파에서 앞선 단계로 이동 시, 연쇄 법칙에 따라 미분값들을 곱하게 된다

⇒ 작은 값들이 반복해서 곱해지면 기울기가 점점 작아지게 된다

⇒ 멀리 거슬러 갈수록 학습 신호가 약해지게 됨 !!!! 기울기 소실문제 발생

오래전에 나온 단어까지 기울기가 전달되려면 매우 많은 단계를 거쳐야 하므로, 작은 미분값이 반복해서 곱해진 상황에 학습 신호가 더 약해지게 됨

### 장거리 의존성(long-distance dependency)

개념) 멀리 떨어진 단어 사이의 관계 ⇒ 다음 단어를 예측하려면 오래전에 나온 단서를 활용해야 하는 경우

![스크린샷 2026-10-06 오후 7.51.53.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_7.51.53.png)

기울기 소실이 심하면, 마지막 예측에서 생긴 학습 신호가 앞부분까지 충분히 전달되지 않게 됨 → 따라서 모델은 오래전 단서를 보존하고 활용하는 방법을 배우기 어려워짐…

즉, 은닉 상태를 전달하는 구조가 있어도 **학습이 잘 된다는 보장이 없는 것** !!!!

### 기울기 폭발(exploding gradient)

역전파 중 기울기가 지나치게 커질 수도 있음 ⇒ 이게 기울기 폭발

이 경우, 파라미터 업데이트가 너무 커져 학습이 불안정해질 수 있다

![스크린샷 2026-10-06 오후 7.55.26.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_7.55.26.png)

위와 같이 기울기가 너무 크면 한 번에 너무 멀리 이동해서 손실이 오히려 커지게 됨

### 기울기 클리핑(gradient clipping)

기울기의 크기가 정해진 한계보다 크면, 방향은 유지하면서 크기만 줄인 뒤 업데이트하는 방식

여기서 벡터의 크기는 노름(norm)으로 측정

![스크린샷 2026-10-06 오후 7.58.05.png](Lecture%205/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-10-06_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_7.58.05.png)

### 기울기 소실의 해결 방향

기본 RNN은 매 단계에서 은닉 상태를 새로 계산하기 때문에 오래전 정보를 보존하도록 학습하기 어려움

해결 방향

- **LSTM:** 별도 메모리와 정보의 흐름을 조절하는 장치를 사용하는 RNN
- **Attention·잔차 연결:** 정보와 학습 신호가 더 직접적으로 전달될 수 있는 연결

| 문제 | 학습에 미치는 영향 | 대응 |
| --- | --- | --- |
| 기울기 소실 | 오래전 단서를 활용하도록 배우기 어려움 | 정보를 보존하고 전달하기 쉬운 구조를 예고 |
| 기울기 폭발 | 업데이트가 너무 커져 학습이 불안정해짐 | 기울기 클리핑 |

## 7. 정리와 다른 활용

### 언어 모델과 RNN의 구분

- 언어 모델(LM): 앞선 문맥으로 다음 단어의 확률을 예측하는 모델
- 순환 신경망(RNN): 순서 있는 입력을 같은 가중치와 은닉 상태로 처리하는 신경망 구조

즉, 언어 모델 = 무엇을 예측하는지 / RNN = 어떻게 계산하는지

### 문장 인코딩

문장을 분류하려면 RNN이 읽은 내용을 문장 전체를 나타내는 벡터 하나로 만들 수 있다

⇒ 이게 바로 문장 인코딩

| 방법 | 문장 벡터를 만드는 방식 |
| --- | --- |
| 마지막 은닉 상태 사용 | 마지막 단어까지 읽은 h_T를 사용 |
| 모든 은닉 상태 모으기 | 각 성분별로 평균 또는 최댓값을 계산 |

+) 성분별 평균은 같은 자리까지 평균을 내는 것을 의미한다

성분별 최대 풀링도 존재 → 이걸 max pooling이라고 한다

### 시퀀스 태깅(sequence tagging)

: 입력의 각 단어에 라벨을 하나씩 붙이는 작업

RNN은 각 단계의 은닉 상태를 이용해 그 위치의 단어에 대한 라벨을 예측할 수 있다

- **문장 분류:** 문장 전체에 라벨 하나
- **시퀀스 태깅:** 단어마다 라벨 하나

### 인코더

입력을 벡터 표현으로 바꾼다

예를 들어 RNN이 질문을 읽어 은닉 상태들을 만들면, 더 큰 질문 응답 시스템이 그 표현을 이용해 답을 찾는다

### 조건부 언어 모델(conditional language model)

앞서 생성한 단어뿐 아니라 **추가 입력도 조건으로 사용해** 다음 단어를 예측
