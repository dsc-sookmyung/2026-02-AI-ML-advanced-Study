# Lecture 6

## 1. 기울기 소실·폭발

### 기울기 소실

기울기 소실 = 먼 과거로 전달되는 학습 신호가 약해지는 현상

역전파 시 연쇄 법칙에 따라 미분값을 반복해서 곱하는 과정

ex. 매 단계 0.5를 곱하는 경우 → 1 → 0.5 → 0.25 → 0.125

⇒ 오래전 단서와 현재 정답 사이의 관계를 학습하기 어려워짐

+) 긴 문장을 처리할 수 있다는 것과 오래전 정보를 잘 활용하도록 학습한다는 것은 별개

### 선형 RNN에서의 원인

활성화 함수를 항등 함수로 둔 단순화 → 시간축을 거슬러 갈수록 같은 가중치 행렬의 반복 곱 등장

특정 방향을 반복해서 축소하는 행렬 → 해당 방향의 기울기 감소

### 기울기 폭발

기울기 폭발 = 역전파 중 기울기가 지나치게 커지는 현상

ex. 매 단계 2를 곱하는 경우 → 1 → 2 → 4 → 8 → 16

업데이트 식 = 새 파라미터 = 현재 파라미터 - 학습률 × 기울기

⇒ 같은 학습률에서도 기울기가 크면 이동량 증가 → 과도한 업데이트와 학습 불안정

### 기울기 클리핑

클리핑 = 기울기 크기가 임계값을 넘을 때, 방향은 유지하고 크기만 줄이는 방법

노름 = 벡터의 길이를 측정하는 값

ex. 기울기 (3, 4)의 노름 = sqrt(3² + 4²) = 5

임계값 2 → 전체 벡터에 2/5를 곱함 → 조정된 기울기 (1.2, 1.6), 노름 2

+) 임계값 이하의 작은 기울기는 그대로 유지

+) 기울기 소실의 해결책은 아님

### 별도 메모리의 필요성

기본 RNN = 매 단계 은닉 상태를 다시 계산하는 구조

⇒ 오래 유지할 정보를 별도 메모리에 저장하는 방향으로 접근해야 함

### 정리

- 폭발 → 클리핑으로 업데이트 크기 제한
- 소실 → 정보를 보존하고 학습 신호를 전달하기 쉬운 구조 필요

## 2. LSTM

### 셀 상태와 은닉 상태

LSTM = 별도 메모리와 게이트를 사용하는 RNN

- 셀 상태 c_t = 오래 유지할 정보를 담는 메모리
- 은닉 상태 h_t = 셀 정보를 바탕으로 만든 현재 단계의 출력 표현

+) 두 상태 모두 길이 n의 벡터

게이트 = 정보의 통과량을 조절하는 장치

유지·쓰기·출력 비율을 현재 문맥에 따라 계산하는 구조

### 망각 게이트(forget gate)

망각 게이트 f_t = 이전 셀 상태의 각 성분을 얼마나 유지할지 조절하는 값

- 1에 가까움 → 대부분 유지
- 0에 가까움 → 대부분 삭제

성분별 곱 = 같은 자리끼리 곱하는 계산

ex. 이전 셀 상태 (6, 4), 망각 게이트 (1, 0.5) → 유지한 정보 (6, 2)

### 입력 게이트(input gate)

입력 게이트 i_t = 새 후보 정보를 셀에 얼마나 쓸지 조절하는 값

- 후보 정보 c_candidate_t = 새로 저장할 내용
- 입력 게이트 i_t = 그 내용을 반영할 비율

ex. 후보 정보 (2, 6), 입력 게이트 (0.5, 0) → 새로 쓸 정보 (1, 0)

### 셀 상태 갱신

새 셀 상태 = 유지한 옛 정보 + 새로 쓸 정보

ex. 유지한 정보 (0, 4), 새 정보 (1, 0) → 새 셀 상태 (1, 4)

⇒ 기존 정보를 무조건 덮어쓰는 대신, 유지할 부분과 추가할 부분을 조절하는 구조

### 출력 게이트(output gate)

출력 게이트 o_t = 셀 정보를 은닉 상태에 얼마나 내보낼지 조절하는 값

은닉 상태 = 출력 게이트와 tanh(새 셀 상태)의 성분별 곱

ex. tanh(셀 상태) = (0.8, 0.6), 출력 게이트 = (1, 0) → 은닉 상태 (0.8, 0)

+) 출력 게이트가 0이어도 셀 메모리는 그대로 남을 수 있음

⇒ 셀의 정보 보존과 현재 은닉 상태로 내보내는 양의 구분

### 차원

입력 임베딩 d차원, 은닉·셀 상태 n차원 기준

- x_t = d차원
- h_prev, c_prev = 각각 n차원
- W = shape (n, n)
- U = shape (n, d)
- b = n차원
- 세 게이트·후보 정보·새 셀 상태·새 은닉 상태 = 모두 n차원

### 계산 예시

c_prev = (6, 4), f_t = (0, 1), i_t = (0.5, 0), c_candidate_t = (2, 6)

- 유지한 옛 정보 = (0 × 6, 1 × 4) = (0, 4)
- 새로 쓸 정보 = (0.5 × 2, 0 × 6) = (1, 0)
- 새 셀 상태 = (0, 4) + (1, 0) = (1, 4)

### 정보 보존

어떤 성분의 망각 게이트 = 1, 입력 게이트 = 0 → 이전 셀 값 그대로 유지

+) 실제 sigmoid에서는 0·1에 가까운 값으로 조절, 정확한 0·1은 원리 이해를 위한 이상적 경우

핵심 = 셀 갱신식의 덧셈 경로

⇒ 기본 RNN보다 정보 보존과 기울기 전달이 쉬워짐

+) 모든 장거리 정보를 반드시 기억하거나 기울기 문제를 완전히 없애는 것은 X

+) 슬라이드의 약 7단계·100단계 비교는 거친 경험적 설명, 고정된 기억 한계는 X

### LSTM 배경

1997년 LSTM 제안 → 이후 망각 게이트 등 발전 → 여러 작업에서 활용

### 잔차·밀집·하이웨이 연결

기울기 소실·폭발 = RNN뿐 아니라 깊은 신경망 전반의 문제

- 잔차 연결 = 변환 결과에 원래 입력을 더하는 구조, 출력 = 입력 + 변환(입력)
- 밀집 연결 = 각 층을 이후 모든 층에 직접 연결하는 구조
- 하이웨이 연결 = 원래 입력을 통과시키는 경로와 변환 경로의 반영량을 게이트로 조절하는 구조

⇒ 정보와 기울기가 더 직접적으로 전달될 경로의 확보

### 정리

- 셀 상태 = 메모리, 은닉 상태 = 현재 출력 표현
- 망각 게이트 = 유지량, 입력 게이트 = 쓰기량, 출력 게이트 = 출력량
- 셀의 덧셈 경로 = 정보 보존의 핵심

## 3. RNN의 다른 활용

### 시퀀스 태깅

: 시퀀스 태깅 = 각 단어에 라벨 하나씩 붙이는 작업

ex. 품사 태깅·개체명 인식

단어 5개 → 출력 라벨 5개

### 문장 인코딩과 분류

문장 인코딩 = 문장 전체를 나타내는 벡터

이를 이용한 긍정·부정 등의 문장 분류

문장 벡터 생성 방법

- 마지막 은닉 상태 사용
- 모든 은닉 상태의 성분별 평균 또는 최댓값 사용

ex. 은닉 상태 (1, 4), (3, 2)

- 평균 = (2, 3)
- 성분별 최댓값 = (3, 4)

+) 큰 숫자를 정렬하는 방식이 아니라 같은 자리끼리 계산

+) 결과 차원은 은닉 상태의 차원과 동일

### 조건부 생성

조건부 생성 = 앞선 출력 단어와 추가 입력을 함께 참고하는 생성

ex. 음성을 참고한 문장 출력, 원문을 참고한 번역

### 정리

- 태깅 = 단어별 라벨 출력
- 분류 = 문장 전체의 라벨 출력
- 조건부 생성 = 추가 입력을 조건으로 문장 생성

## 4. 양방향·다층 RNN

### 문맥 표현

문맥 표현 = 주변 문맥을 반영한 단어의 벡터 표현

순방향 RNN = 현재 단어와 왼쪽 문맥 반영, 아직 읽지 않은 오른쪽 문맥은 미반영

ex. `the movie was terribly exciting`

`terribly` 뒤의 `exciting`까지 확인 → 부정적 표현으로만 해석하기 어려움

### 양방향 RNN

양방향 RNN = 순방향·역방향 RNN을 함께 사용하는 구조

- 순방향 = 왼쪽부터 오른쪽으로 처리
- 역방향 = 오른쪽부터 왼쪽으로 처리

각 위치의 두 은닉 상태를 이어 붙임 → 양쪽 문맥을 담은 표현

+) 두 방향은 일반적으로 별도 가중치 사용

+) 각 방향이 n차원이면 연결 결과는 2n차원

전체 입력이 주어진 태깅·분류·번역 인코더 등에 적용 가능

미래 단어가 없는 다음 단어 생성에는 그대로 적용 불가

+) 언어 모델 제한은 왼쪽에서 오른쪽으로 다음 단어를 생성하는 경우에만 해당

### 다층 RNN

다층 RNN = RNN을 여러 층 쌓은 구조, stacked RNN

아래층의 각 위치 은닉 상태 → 위층의 같은 위치 입력

⇒ 시간축 반복에 층 방향의 깊이를 추가하여 더 복잡한 표현 학습

- 층끼리는 서로 다른 파라미터 사용
- 각 층 내부에서는 시간 단계마다 같은 가중치 공유

+) 층을 많이 쌓을수록 항상 좋은 것은 아님

+) 깊은 구조의 학습에 skip connection 등이 도움

### 활용 배경

2013–2015년 무렵 LSTM의 여러 NLP 작업 성공 → 이후 Transformer 중심으로 변화

### 정리

- 양방향 = 양쪽 문맥 활용
- 다층 = 여러 층에 걸친 표현 계산
- 양방향과 다층의 동시 적용 가능

## 5. 기계 번역과 통계적 번역

### 기계 번역(MT)

기계 번역 = 출발 언어 문장 x를 목표 언어 문장 y로 번역하는 작업

초기 접근 = 단어 치환 등의 규칙 기반 번역

언어별 어순·의미·표현 차이 → 단순 치환의 한계

### 통계적 기계 번역(SMT)

SMT = 데이터에서 학습한 확률 모델로 번역을 선택하는 방법

목표 = 원문 x가 주어졌을 때 P(y given x)가 가장 큰 번역 y 선택

베이즈 규칙 적용 → P(x given y) × P(y)가 가장 큰 y 선택

+) 같은 원문에 대한 P(x)는 후보마다 공통이므로 비교에서 생략

두 모델의 역할

- 번역 모델 P(x given y) = 원문과 번역의 대응 모델, 의미의 충실도와 관련
- 언어 모델 P(y) = 목표 언어 문장의 자연스러움 모델, 유창성과 관련

학습 데이터

- 번역 모델 → 원문·번역 쌍인 병렬 데이터
- 언어 모델 → 목표 언어의 단일언어 데이터

### 번역의 어려움

단어·구절 대응, 어순 변화, 의미 관계 등의 처리 필요

기존 SMT = 많은 구성 요소·특징 설계·구절 대응표 등 자원 필요

⇒ 언어 쌍마다 설계와 유지 부담

### 정리

- 번역 = 단어 치환 이상의 작업
- SMT = 충실도를 위한 번역 모델 + 유창성을 위한 언어 모델
- 한계 = 복잡한 시스템 구성과 유지 부담

## 6. 신경망 기계 번역 (PDF 49–55)

### 신경망 기계 번역(NMT)

NMT = 인코더와 디코더를 하나의 신경망 시스템으로 학습하는 번역

ㄴ 구조 = 두 RNN을 이용한 seq2seq

seq2seq = 입력 시퀀스를 출력 시퀀스로 바꾸는 모델

### 인코더–디코더

- 인코더 = 원문을 읽고 벡터 표현 생성
- 디코더 = 원문 표현을 조건으로 번역 단어를 순서대로 예측

기본 구조 = 원문 표현을 디코더의 초기 은닉 상태로 전달

START 입력 → 첫 번역 단어 예측 → 생성한 단어를 다음 입력으로 사용 → END에서 종료

+) 그림의 단어 선택 방식 = 가장 높은 점수 후보를 고르는 argmax

+) 생성 방식이 항상 샘플링인 것은 아님

### 조건부 언어 모델

디코더 = 다음 목표 단어를 예측하는 언어 모델

추가 조건 = 원문 x

번역 확률 = 각 단계의 P(다음 번역 단어 given 앞선 번역 단어들, 원문 x)를 모두 곱한 값

seq2seq의 다른 활용 = 요약·대화·파싱 결과 생성·코드 생성

### 병렬 데이터와 학습

병렬 코퍼스 = 원문과 정답 번역을 짝지은 데이터

- 인코더 입력 = 원문
- 디코더 입력 = START와 앞선 정답 번역 단어들
- 예측 정답 = 다음 번역 단어

⇒ teacher forcing을 이용한 학습

각 단계 손실 = 정답 다음 단어 확률의 음의 로그

전체 손실 = 단계별 손실의 평균

end-to-end 학습 = 디코더에서 인코더까지 역전파하여 전체 시스템을 함께 학습

+) 생성 시에는 정답 번역이 없으므로 자신이 생성한 단어를 다음 입력으로 사용

### 다층 구조와 정보 병목

인코더·디코더에도 여러 RNN 층 적용 가능

기본 구조 = 원문 정보를 고정 크기 표현에 담아 디코더로 전달

긴 원문 → 필요한 정보를 하나의 표현에 담기 어려워짐

정보 병목 = 이처럼 제한된 표현을 거쳐 정보를 전달하는 구조적 제약

+) 이 강의의 설명 범위는 병목까지, attention의 구체적 구조는 이후 내용

### 역사적 성공

2014년 무렵 seq2seq 연구 → 2016년 Google 번역의 NMT 전환 등 빠른 확산

### 정리

- 인코더 = 원문 표현 생성
- 디코더 = 원문 표현과 앞선 출력으로 번역 생성
- 학습 = 원문·정답 번역 쌍으로 두 부분을 함께 학습
- 기본 구조의 한계 = 고정 크기 원문 표현의 정보 병목

## 전체 정리

- LSTM = 셀 메모리와 게이트를 이용한 정보 보존
- 클리핑 = 큰 기울기만 줄여 업데이트 크기 제한
- 양방향 = 전체 입력이 있을 때 양쪽 문맥 활용
- 다층 = 아래층 은닉 상태를 위층 입력으로 사용
- 인코더–디코더 = 입력 표현을 조건으로 출력 생성
- NMT = 원문 조건부 언어 모델, 병렬 데이터 기반 end-to-end 학습

### 헷갈리지 말 것

- 셀 정보 보존과 은닉 상태 출력은 별개
- 후보 정보는 내용, 입력 게이트는 반영 비율
- 양방향은 처리 방향, 다층은 쌓는 층의 수
- 언어 모델은 예측 작업, RNN·LSTM은 계산 구조
- 학습의 teacher forcing은 정답 입력, 생성은 자신의 출력 입력
- 성분별 곱은 같은 자리끼리 곱하기, 행렬 곱은 차원 변환, 이어 붙이기는 차원 합산
